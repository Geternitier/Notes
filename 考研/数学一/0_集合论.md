# 集合论

## 1. 集合

### 1.1 概念

**集合**是指一些对象的全体，这些对象称为集合的元素。

常用大写字母A、B、C表示集合，用小写字母a、b、c表示集合的元素。
1. $a\in A$表示$a$是$A$的元素，$a\notin A$表示$a$不是$A$的元素。
2. $a=b$表示元素$a,b$相同，$A=B$表示集合$A,B$相同。
3. $A\subset B$表示$A$对所有元素都在$B$中，称$A$为$B$的**子集**。
   - 有时用$A\subseteq B$表示$A$是$B$的子集且$A$和$B$可能相等，此时用$A\subset B$表示$A$是$B$的子集且$A$和$B$不相等，也称$A$为$B$的**真子集**。



### 1.2 集合公理

**集合公理**是对集合的一些直觉的显式规定。通过这些规定可以构造出所有集合。

1. 空集公理：存在不含任何元素的集合，称为空集，记为$\varnothing$。
2. 外延公理：具有相同元素的集合是相同的集合。
3. 无序对公理：任意元素x、y，存在集合恰好含有x、y。
4. 并集公理：设F为一族集合，存在A满足$\forall x\in A\Longleftrightarrow \exists X\in F有x\in X$。A称为F的并集。
5. 幂集公理：集合A的所有子集构成一个集合，称为A的幂集。
6. 无穷公理：存在具有无限个元素的集合。
7. 分离公理：可以在集合A中按某种方式挑选一些元素构成一个新的集合。
8. 替换公理：可以按照某种映射关系从集合A构造新集合B。即$B=\{F(x):x\in A\}$。
9. 正则公理：$\forall A\neq\varnothing,\exists a\in A使a\cap A\neq\varnothing$。
10. 选择公理：一族非空且两两不交的集合，可以在其中每个集合选一个元素组成一个集合。



## 2. 关系

### 2.1 有序对

**有序对**是两个元素的有序组合，写作$(x,y)$，满足$(x,y)=(u,v)$当且仅当$x=u,y=v$。

1. 集合$A$和$B$的**笛卡尔积**$A\times B$是对任意的$a\in A,b\in B$，全部的$(a,b)$构成的集合。
2. 有序对的集合称为**关系**，$A$到$B$的一个关系是$A\times B$的子集。



### 2.2 等价关系

关系$R$在$A$上满足自反、对称和传递性，称$R$在$A$上为**等价关系**。

1. $\forall x\in A$，有$(x,x)\in R$，称$R$在$A$**自反**；
2. $\forall (x,y)\in R$，有$(y,x)\in R$，称$R$**对称**；
3. $\forall(x,y)\in R\land (y,z)\in R$，有$(x,z)\in R$，称关系$R$有**传递性**。

禁自反、禁对称和反对称：

1. $\forall x\in A$，有$(x,x)\notin R$，称$R$在$A$**禁自反**；
2. $\forall (x,y)\in R$，有$(y,x)\notin R$，称$R$**禁对称**；
3. $\forall(x,y)\in R$，有$(y,x)\in R$当且仅当$x=y$，称$R$**反对称**。



### 2.3 序关系

$R$在$A$上满足传递性和三分性，则$R$在$A$上为**序关系**。

1. $\forall x,y\in A$，三种情形$(x,y)\in R;(y,x)\in R;x=y$仅有一种成立，称$R$在$A$上有**三分性**。
2. 具备序关系的集合称为**有序集**。

偏序、全序关系：

1. $R$在$A$上满足自反、反对称和传递性，称$R$在$A$上为**偏序关系**；
2. $R$为$A$上偏序，且$\forall x,y\in A$，有$(x,y)\in R$或$(y,x)\in R$，称$R$在$A$上为**全序关系**。
3. $R$在$A$上满足禁自反、禁对称和传递性，称$R$在$A$上为**严格偏序关系**。

良序定理：

1. $R$为$A$上偏序，$\exists b\in A$使得$\forall x\in A\land x\neq b$，有$(b,x)\in R$，称$b$为$A$的$R$**偏序极小元**。
2. 具有偏序极小元的全序关系称为**良序关系**。
3. 良序定理：任何集合都可以被良序。这等价于选择公理。



### 2.4 上确界性质

1. 集合$S$，偏序$\lt$，对$S$的子集$E$，若$\exists M\in S$，使得$\forall y\in E$有$y\lt M$，称$M$为$E$的**上界**；
2. 进一步，若$\forall z\in S\land z\lt x$有$z$不是$E$的上界，则$x$为$E$的**上确界**。
3. 集合$S$，偏序$\lt$，对$S$的子集$E\ne\varnothing$，若$E$有上界$\Longrightarrow E$有上确界，称$R$在$S$具有**上确界性质**。



## 3. 映射

### 3.1 映射

**映射**，也称**函数**，集合$X$到$Y$的映射$f:X\rightarrow Y$是$X\times Y$的子集，满足$\forall x\in X$有唯一$(x,y)\in f$。

1. 集合$X$称为$f$的**定义域**，记为$\mathrm{Dom}f$。
2. $f(X)=\{f(x):x\in X \}$称为$f$的**值域**，也称**像集**，记为$\mathrm{Ran}f$或$\mathrm{Im} f$。
4. $f(X)$是$Y$的子集，称$Y$为函数$f$的**陪域**。
5. 定义域、对应关系和陪域唯一确定一个映射。
   - 映射作为有序对集合是定义域和陪域的笛卡尔积的子集，因此陪域也很重要。
   - 如果没有陪域，满射、双射等便于研究映射性质的概念便没有意义了。

映射的表示方法：

1. 命题法，对任意的$x\in X$，存在$y\in Y$使得$y=f(x)$，即$\{y\in Y:y=f(x),x\in X\}$。
2. 枚举法。
3. 表达式，实质是已知映射的组合。
4. 算法。
5. 选择公理。

一元、多元、多维函数：

1. 记$k$个$\mathbb R$的笛卡尔积为$\mathbb R^k$，其中元素是$k$元有序序列。
2. 称定义域为$\mathbb R$的函数为一元函数，定义域为$\mathbb R^k$的函数为$k$元函数。
3. 称陪域为$\mathbb R$的函数为一维函数，陪域为$\mathbb R^k$的函数为$k$维函数。



### 3.2 映射和解方程

#### 单射、满射和双射

$f:X\rightarrow Y$，

1. 若对任意的$x_1,x_2\in X$，有$x_1\neq x_2\implies f(x_1)\neq f(x_2)$，称$f$是一个单射。
2. 若$f(X)=Y$，称$f$是一个满射。
3. 若$f$既是单射，也是满射，则称$f$是一个一一对应，也称双射。



#### 方程的解

$f:X\rightarrow Y$

1. 所谓解方程，就是已知陪域中的元素，求满足$(x,y)\in f$的所有$x$。
2. 解方程的过程，往往是给定隐函数（判别式），求解参数方程（生成式）的过程。
3. 解方程的问题就是研究映射性质的问题：
   - 方程有解的充要条件：要求解的函数值属于$f$的值域。
   - 方程一定有解的充要条件：$f$是满射。
   - 方程有解时解唯一的充要条件：$f$是单射。
   - 方程一定有解且解唯一的充要条件：$f$是双射。



### 3.3 反函数和复合函数

$f:X\rightarrow Y,g:Y\rightarrow Z$，

1. 若$\{(y,x):(x,y)\in f\}$也是一个函数，则称其为$f$的反函数，记为$f^{-1}$。
   - $f$有反函数，当且仅当$f$是$X$到$f(X)$的一一对应。
2. $h(x)=g(f(x)):X\rightarrow Z$也是一个函数，称为$g$和$f$的复合函数，记为$g\circ f$。



### 3.4 有限和可数

若集合$A$和$B$上有一一对应，称$A$和$B$**等势**，记为$A\sim B$。

1. 有限：和有限自然数集$\{1,2,...,n\}$等势。
2. 无限：不和有限自然数集$\{1,2,...,n\}$等势。
3. 可数：和自然数集$\mathbb N$等势。
4. 不可数：既不有限，也不可数。

序列是$\mathbb N$一一对应的一个像集，$x_n=f(n)$。

序列的子列仍然是序列$\Longleftrightarrow$可数集的无限子集仍然可数（可数集是"最小"的无限集）

有理数集可数，实数集不可数。
