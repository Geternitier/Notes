# 概率论与数理统计



## 1. 随机事件



### 1.1

随机事件$A,B$满足$0\lt P(A),P(B)\lt 1$，则$P(AB)\gt P(A)P(B)$的充要条件是：

1. $P(A\overline B)\gt P(A)P(\overline B)$；
2. $P(\overline A\overline B)\gt P(\overline A)P(\overline B)$；
3. $P(B|\overline A)\gt P(B|A)$；
4. $P(A|\overline B)\gt P(A|B)$。

答案：2。

思路：

1. $P(AB)=P(A|B)P(B)\gt P(A)P(B)$，于是$P(A|B)\gt P(A)$；
2. 又因为$P(A)=P(AB)+P(A\overline B)=P(A|B)P(B)+P(A|\overline B)P(\overline B)$，可得$P(A|\overline B)\lt P(A)\lt P(A|B)$，4错，同理3错；
3. 于是$P(\overline A|\overline B)\gt P(\overline A)\gt P(\overline A|B)$；
4. $P(A\overline B)=P(A|\overline B)P(\overline B)\lt P(A)P(\overline B)$，1错；
5. $P(\overline A\overline B)=P(\overline A|\overline B)P(\overline B)\gt P(\overline A)\overline B$，2对。

**补充**：

$P(AB)\gt P(A)P(B)$，称$A,B$正相关，$B$发生时$A$发生概率更大；

$P(AB)\lt P(A)P(B)$，称$A,B$负相关，$B$发生时$A$发生概率更小；

$A,B$正相关时，$\overline A,B$负相关，$\overline A,\overline B$正相关。



## 2. 随机变量

### 2.1

$X,Y$和$X+Y$均服从同一种分布，其中$X,Y$相互独立，则下列分布一定满足的是：

1. 均匀分布
2. 泊松分布
3. 指数分布
4. 二项分布

答案：2

思路：

1. $X,Y\sim U(0,1)$，$P(Z\le z)$是$y=z-x$截$x\in[0,1],y\in[0,1]$的左下面积，不是均匀分布，1错；
2. $X\sim P(m),Y\sim P(n)$，$P(X+Y=k)=\sum_{i=0}^kP(X=i)P(Y=k-i)=\frac{\mathrm e^{-m-n}(m+n)^k}{k!}$，是泊松分布，2对；
3. $X,Y\sim E(\lambda)$，$F(Z=X+Y\le z)=\int_0^z\int_0^{z-x}\lambda^2\mathrm e^{-\lambda x}\mathrm e^{-\lambda y}\mathrm dy\mathrm dx=1-\mathrm e^{-\lambda z}-\lambda z\mathrm e^{-\lambda z}$，$f(z)=F'=\lambda^2z\mathrm e^{-\lambda z}$，不是指数分布，3错；
4. $X\sim\mathbb B(m,p),Y\sim\mathbb B(n,q)$，$X+Y$服从二项分布的前提是$p=q$，4错。



### 2.2

随机变量$X$的概率密度$f=\frac x2,x\in(0,2)$，$Y=-\ln(1-F_X)$，求$P(Y\gt\frac12)$。

答案：$\mathrm e^{-\frac12}$。

思路：

1. $Y\gt\frac12$，即$F_X\gt 1-\mathrm e^{-\frac12}$；
2. $F_X\sim U(0,1)$，$P(F_X\gt1-\mathrm e^{-\frac12})=\mathrm e^{\frac12}$。

**补充**：

任意一维连续随机变量$X$，$F_X\sim U(0,1)$。



### 2.3

区间$[0,1]$上任取一点划分两个区间，其中一个区间长$X$，在这个区间中任取一点划分两个区间，其中一个区间长$Y$，求$E(Y)$。

答案：$\frac14$。

思路：

1. $E(X)=\frac12,E(Y|X)=\frac X2$，则$E(Y)=E(E(Y|X))=E(\frac X2)=\frac14$；
2. $f_X=1,f_{Y|X}=\frac1x$，则$f=\frac1x$，$E(Y)=\int_0^1\int_0^xy\frac1x\mathrm dy\mathrm dx=\frac14$。



### 2.4

$(X,Y)\sim\mathbb N(0,0,\sigma^2,\sigma^2,0)$，若$D(|X-Y|)=1-\frac2\pi$，求正数$\sigma$。

答案：$\frac1{\sqrt2}$。

思路：

1. $Z=X-Y\sim\mathbb N(0,2\sigma^2)$；
2. $D(|Z|)=2\int_0^{+\infty}z\frac1{\sqrt{2\pi}\sqrt2\sigma}\mathrm e^{-\frac{z^2}{4\sigma^2}}\mathrm dz=2\sigma^2(1-\frac2\pi)$，因此$\sigma=\frac1{\sqrt2}$。

**补充**：

$X\sim\mathbb N(0,\sigma^2)$，则$E(X)=\sigma\sqrt{\frac2\pi},D(X)=\sigma^2(1-\frac2\pi)$。



### 2.5

连续随机变量$X,Y$独立同分布，分布函数$F(X)$严格单调增加，若$E(|X-Y|)=1$，求$\mathrm{Cov}(X,F(X))$。

答案：$\frac14$。

思路：

1. $|X-Y|=\max(X,Y)-\min(X,Y)$；
2. $P(\max(X,Y)\le z)=P(X\le z)P(Y\le z)=F(z)^2$，$f_\max=2FF'$；
3. $P(\min(X,Y)\le z)=1-P(X\gt z)P(Y\gt z)=2F-F^2$，$f_\min=2F'-2FF'$；
4. $E(|X-Y|)=\int z(f_\max-f_\min)\mathrm dz=4\int zF\mathrm dF-2\int z\mathrm dF=4E(XF)-2E(X)$；
5. $\mathrm{Cov}(X,F)=E(XF)-E(X)E(F)$，其中$E(F)=\frac12$；
6. $\mathrm{Cov}(X,F)=\frac14E(|X-Y|)=\frac14$。
