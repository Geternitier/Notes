# DSA



## 1. 绪论

**数据类型**是一类数据元素的集合和定义在此集合上的一组操作的总称。

1. **原子类型**是值不可再分的数据类型；
2. **结构类型**是值可以再分解为若干分量的数据类型；

数据类型中元素相互之间的关系称为**数据结构**，包括**逻辑结构**、**存储结构**和**运算**。

1. 逻辑结构包括**线性结构**、**非线性结构**，存储结构包括**顺序**、**链式**、**索引**、**散列**。
2. 数据运算的定义取决于逻辑结构，实现取决于物理结构。
3. **抽象数据类型 ADT**是对数据类型逻辑结构和运算定义的抽象，与物理实现无关。



**算法**是对特定问题求解步骤的描述，具有下述性质：

1. **有穷性**：有穷步数，有穷时间
2. **确定性**：相同输入，相同输出
3. **可行性**：操作可由有限次已定义的基本运算实现
4. **输入和输出**

好的算法的目标：**正确性**、**可读性**、**健壮性**（处理异常输入）、**高效率**、**低存储**

时间复杂度和空间复杂度用于度量**算法效率**。

1. **时间复杂度**是算法执行时间随问题规模n变化的数量级
   1. 可以用算法中所有语句的频度和的数量级计算；
   2. **最好时间复杂度**是算法在最有利输入下的运行时间数量级；
   3. **最坏时间复杂度**是算法在最不利输入下的运行时间数量级；
   4. **平均时间复杂度**是算法所有输入下的期望运行时间数量级。
2. **空间复杂度**是算法所需**额外存储空间**。



## 2. 线性表

### 2.1 线性表

#### 概述

**线性表**是$n$个相同数据类型元素的有限序列，$L:\{i:i\in\mathbb N,i\le n\}\rightarrow \mathrm{ADT}$。

1. 常用运算有**求表长**、**插入**、**删除**、**按位查值**、**按值查位**。
2. 物理结构有**顺序**和**链式**。
   1. 顺序存储密度高，但需要连续存储空间；
   2. 链式存储无法随机访问，但头插/尾插方便。

**顺序存储**指用一组地址连续的存储单元存储依次线性表的元素，编程中称为**数组**。

1. 按值查位：遍历表，时间复杂度$O(n)$。
2. 按位查值：**随机访问**，时间复杂度$O(1)$。
3. 插入/删除：执行操作并移动操作位置后的所有元素，时间复杂度$O(n)$。

**链式存储**使用「数据｜后继」的节点逐个存储线性表的元素。



#### 链表

节点为「数据｜后继」的链式存储称为**单链表**。

1. 按位查值：遍历表，时间复杂度$O(n)$。
2. 插入/删除：先查找后操作，时间复杂度$O(n)$。

物理实现的优化：记录指向首个节点的指针称为**头指针**，一般尾节点后继为空。

1. 为简化运算，常添加空数据、指向首节点的**头节点**，头指针指向头节点。
2. 常记录指向尾节点指针用于尾部插入，称为**尾指针**。
3. 尾节点后继为首节点/头节点，称为**循环单链表**。循环单链表可不设头指针，仅设尾指针。

节点为「前驱｜数据｜后继」的链式存储称为**双链表**。

使用顺序存储，每个存储单元存储「数据｜后继序号」模拟链表的结构称为**静态链表**。



#### 数组压缩

1. 上/下三角矩阵：按行或列序依次存储上/下三角元素到一维数组中。
2. 对称矩阵：转化为上/下三角矩阵。
3. 三对角矩阵：非零元素集中在以主对角线为中心的3条对角线上的矩阵。
   - 按行或列序依次存储到一维数组中。
4. 稀疏矩阵：非零元素数远小于矩阵元素数。
   - 三元组存储：顺序存储「行｜列｜值」，记录行数、列数、非零元素数。
   - 十字链表：链式存储「行｜列｜值｜行下个非零｜列下个非零」，顺序存储每行列首个非零节点。



#### 算法

双指针；

**模式匹配**是在串中查找与模式串相同的子串，**KMP算法**基于最长公共前后缀串进行匹配。

1. 模式串为need，数组next和need长度相同。
2. $\mathrm{next}[i]$表示$\mathrm{need}[0\dots i]$前缀与后缀的最大相同时的前缀末尾位置。
   - 若表示最长相同前后缀长度，则该表称为**前缀表**。
3. 匹配时，如果第$i+1$位不匹配，可以根据$\mathrm{next}[i]$回退匹配。

$\mathrm{need}[0\dots i]$表示从0到i位的i+1个元素构成的串。

```C++
void getNext(int* next, const string& s) {
    int j = -1;
    next[0] = j;
    for (int i = 1; i < s.size(); ++i) {
        while (j >= 0 && s[j + 1] != s[i]) j = next[j];
        if (s[j + 1] == s[i]) ++j;
        next[i] = j;
    }
}

int findStr(string s, string need) {
    int* next = new int[need.size()];
    getNext(next, need);
    int pos = -1;
    for (int i = 0; i < s.size(); ++i) {
        while (pos >= 0 && s[i] != need[pos + 1]) {
           pos = next[pos];
        }
        if (s[i] == need[pos + 1]) ++pos;
        if (pos == need.size() - 1) return i - pos;
    }
  
    return -1;
}
```



### 2.2 栈和队列

#### 双端队列

只在两端插入/删除的线性表称为**双端队列**。

1. 限制某一端插入/删除能力的双端队列称为**受限双端队列**；
2. 只在一端插入、另一端删除的双端队列称为**队列**，插入端称为**队尾**，删除端称为**队头**；
3. 只在一端插入/删除的双端队列称为**栈**，该端称为**栈顶**，另一端称为**栈底**。

双端队列的常用运算有**查队长**、**查看队头/队尾元素**、**队头插入/删除**、**队尾插入/删除**。

1. 栈的栈顶插入称为**压栈**，栈顶删除称为**出栈**；
2. 队的插入称为**入队**，删除称为**出队**。
3. 卡特兰数公式：当$n$个不同元素按一定顺序压栈，出栈序列的排列数为$\frac1{n+1}C_{2n}^n$。



#### 存储

双端队列常使用顺序、链式，以及两者复合的存储方式。

顺序存储时，依次存储队中元素，并记录双端位置。

1. 栈通常以位置0为栈底，记录栈顶位置；
2. 常将一个顺序存储空间的两端作为两个栈底，两个栈顶向中间延伸，这称为**共享栈**。
3. **循环队列**中，入/出队到容量上限后从0继续，避免已出队位置被浪费。

循环队列判满与判空的三种方法

1. 记录元素数；
2. 队尾指针指向队尾元素的后一个位置，牺牲该存储位置。
   1. 判空：队尾=队头；
   2. 判满：(队尾+1)%容量=队头；
3. 使用一个标志，当删除后队尾=队头即队空，插入后队尾=队头即队满。



#### 算法

栈常用算法：括号匹配、逆波兰表达式求值、递归算法迭代化

队列常用算法：广度优先遍历、缓冲区管理



## 3. 树

### 3.1 概述

**树**是若干个节点的有限集合，一棵非空树满足：

1. 有且仅有一个节点称为**根**；
2. 非根节点可分为互不相交的有限集合，每个集合是一棵树，并且是根的子树。

若干个互不相交的树的集合称为**森林**。

**基本概念**：

1. 两个节点之间经过的节点序列称为**路径**，**路径长度**为经过边的总长度。
2. 节点$K$到根的路径上的所有其他节点为$K$的**祖先**，$K$是它们的**子孙**。
3. 节点$K$到根的路径上离$K$最近的其他节点为其**双亲**，$K$是它的**孩子**。
4. 双亲相同的节点称为**兄弟**，双亲同层的节点称为**堂兄弟**。
5. 一个节点的孩子数称为该**节点的度**。树中节点的最大度数称为**树的度**。
6. 度为0的节点为**叶**，否则为**分支**。
7. 根为1层，根的孩子为2层，类推；树的**深度/高度**为其最大层数。
8. 节点的左右子树有顺序、不能互换的树为**有序树**，否则为**无序树**。

**计算性质**：

1. 节点总度数=子节点数，节点数=节点总度数+1；
2. 度为$m$的树中第$i$层上至多有$m^{i-1}$个节点；
3. 高$k$的$m$叉树至多有$\sum_{i=1}^km^{i-1}=\frac{(m^k-1)}{m-1}$个节点；
4. 度$m$、$n$节点的树的最小高度为$\lceil\log_m(n(m-1)+1)\rceil$。

**树的存储**：

1. **双亲表示法**：使用数组存储节点，每个节点记录其值与双亲的下标。
2. **孩子表示法**：每个节点的孩子用一个线性单链表存储。
3. **左孩子右兄弟表示法**：第一个孩子的根作为左子节点，下一个兄弟的根作为右子节点。

树、森林可使用左孩子右兄弟表示法转化为二叉树。



### 3.2 二叉树

#### 概述

**二叉树**是度不大于2的有序树，且当节点只有一个子节点，二叉树仍然区分子节点的左右。

1. 高$h$、$2^h-1$节点的二叉树称为**满二叉树**；可按从上到下、从左到右进行节点编号。
2. 高$h$、$n$节点的二叉树，节点在满二叉树中编号前$n$节点位置，称为**完全二叉树**。
3. 每个分支节点度为2的二叉树称为**正则二叉树**。

**蕴含性质**：

1. 设二叉树度为$0,1,2$的节点数为$n_0,n_1,n_2$，则$n_0=n_2+1$。
2. $n$节点的完全二叉树：
   1. 高度为$\lceil\log_2(n+1)\rceil$或$\lfloor\log_2n\rfloor+1$；
   2. 节点$x$在$\lfloor\log_2x\rfloor+1$层，其左子节点为$2x$，右子节点$2x+1$，父节点$\lfloor\frac x2\rfloor$；
   3. 节点$x$是叶节点当且仅当$x\gt\lfloor\frac n2\rfloor$，叶节点只会在最后两层；
   4. 度为1的节点最多有1个，此时$n$为偶数；

**二叉树的存储**：

1. 顺序存储：按照满二叉树编号位置存储二叉树节点，编号位置不存在的节点置0；
2. 链式存储：使用「左子节点｜数据｜右子节点」链式存储；

   - 在含有$n$个节点的二叉链表中含有$n+1$个空链域$\rightarrow$线索二叉树。

3. **线索二叉树**：「左标记｜左子节点｜数据｜右标记｜右子节点」
   1. 使用左右标记位标记是否有左右子树；
   2. 若无左子树，则左指针指向前驱节点，若无右子树，右指针指向后继节点。
   3. 构建过程：一次遍历。


**二叉树的遍历**：

1. **先序**：从根开始，按**根$\rightarrow$左子树$\rightarrow$右子树**顺序遍历每个节点。
2. **中序**：从根开始，按**左子树$\rightarrow$根$\rightarrow$右子树**顺序遍历每个节点。
3. **后序**：从根开始，按**左子树$\rightarrow$右子树$\rightarrow$根**顺序遍历每个节点。
4. **层序**：逐层从左到右遍历。

可根据「中序+先序/后序/层序」遍历序列还原二叉树，其余组合均无法唯一确定二叉树。



#### 哈夫曼树

节点被赋予的数值称为**权**，节点到根的路径长度和权的乘积称为节点的**带权路径长度**，**树的带权路径长度**是树中所有叶节点的带权路径长度之和。

**哈夫曼树**是含若干个带权叶节点的、带权路径长度最小的二叉树，构造过程如下：

1. 将n个节点视为n个树。
2. 构造一个新节点，选取根权值最小的两棵树作为其左右子树，新节点的权为两树根权之和。
3. 重复2直至只剩下一棵树。

每个元素用相等长度二进制编码称为**固定长度编码**，不同元素可用不同长度二进制编码称为**可变长度编码**，满足没有一个编码是其他编码的前缀的编码称为**前缀编码**。

**哈夫曼编码**使用字符出现的频度作为权，将每个字符作为节点构建哈夫曼树，进行前缀编码。

示例：频度A为6，B为3，C为2，D为1，可用0表示A，10表示B，110表示C，111表示D。



## 4. 图

### 4.1 概述

#### 概念

**图**包括**非空有限点集 V**和**边集 E**，记为$G=(V,E)$。$|V|$表示点数，$|E|$表示边数。

基础概念：

1. $G'=(V',E'),G=(V,E)$，若$V'\sub V,E'\sub E$，称$G'$为$G$的**子图**。
   - 若$V’=V$，则称$G'$为$G$的**生成子图**。
2. 边不具有方向的图称为**无向图**，边具有方向的图称为**有向图**。
3. 不存在重复边、顶点到自己的边的图称为**简单图**，否则称为**多重图**。
4. 每个点之间都具有边称为**完全图**。
   - $n$点无向图，$|E|\le \frac12n(n-1)$，取等当且仅当它是无向完全图。
   - $n$点有向图，$|E|\le n(n-1)$，取等当且仅当它是有向完全图。
5. 边上带有权值的图称为**有权图**，也称为**网**。
6. 边数很少的图称为**稀疏图**，反之称为**稠密图**。

**度**：

1. **无向图的度**是与顶点相连的边的总数，边数=度数总和的二分之一。
2. **有向图的入度**为其入边数、**出度**为其出边数，**度**为入度和出度的和。
   - 有向图的**入度总和**=**出度总和**=**边数**。
3. 一个点入度为0，其余点入度为1的有向图称为**有向树**。

**路径**：

顶点序列$P=i_1,...i_k$，$\forall 1\le j\le k$，边$(i_j,i_{j+1})\in G$，称$P$为$G$中一条$i_1$到$i_k$的**路径**。

1. 路径上的边数称为**路径长度**；两点间最短路径长度称为**距离**，若两点间无路径则距离为$\infin$。
2. 第一个顶点与最后一个顶点相同的路径称为**回路**；
3. 除首尾点外所有点不重复的路径称为**简单路径**；首尾为相同点的简单路径称为**简单回路**。

**连通**：

在无向图中，如果两点间存在路径，则两点**连通**。

1. 任意两点连通的无向图为**连通图**；
2. 额外添加任意点就不连通的连通子图称为**极大连通子图**，也称**连通分量**；

有向图中，若顶点对$i,j$间存在$i$到$j$和$j$到$i$的路径，则这两个顶点**强连通**。

1. 任意两点强连通的有向图为**强连通图**。
2. 额外添加任意点就不连通的强连通子图称为**极大强连通子图**，也称**强连通分量**。

**生成树**：

包含连通图中所有顶点的极小连通子图称为**生成树**。

一个带权连通无向图，权值之和最小的生成树称为**最小生成树**。

1. 若图存在权值相同的边，则最小生成树可能不唯一；
2. 最小生成树的权值之和是唯一的；
3. 最小生成树的边数为顶点数减一。



#### 存储

**邻接矩阵**是矩阵$\boldsymbol A=(a_{ij})_{n\times n}$，若存在边$(i,j)$则$a_{ij}$为1或权值。

**邻接表**顺序存储顶点链表，减少了稀疏图的存储需求。

1. 顺序存储每个顶点节点「点$v$｜下个和$v$相连顶点」；
2. 每个顶点节点通过单链表记录和它相连的所有节点。
3. 对有向图，邻接表一般记录出边指向顶点；记录入边的称为逆邻接表。

**邻接多重表**顺序存储顶点边链表，用于无向图。

1. 顺序存储每个顶点节点「点$v$｜$v$的一条边」；
2. 边节点「点$v$｜$v$的下条边｜点$w$｜$w$的下条边｜data」。

**十字链表**顺序存储顶点边链表，用于有向图。

1. 顺序存储每个顶点节点「点$v$｜$v$的一条入边｜$v$的一条出边」；
2. 边节点「点$v$｜$v$的下条边｜点$w$｜$w$的下条边｜data」。



#### 遍历

深度优先遍历、广度优先遍历：

邻接矩阵时间复杂度$O(|V|^2)$，邻接表时间复杂度$O(|V|+|E|)$。



### 4.2 算法

#### 最小生成树

带权连通无向图$G=(V,E)$，$U$为顶点集$V$的一个非空子集，若$(u,v)$是一条具有最小权值的边，其中$u\in U,v\in V-U$，则必存在一棵包含边$(u,v)$的最小生成树。

**Prim算法**：时间复杂度为$O(|V|^2)$，适合边稠密的图。

1. 树$T=(V',E')$，其中$V'=\varnothing,E'=\varnothing$，向空点集$V'$中添加图的任一顶点，
2. 循环：
   1. 若$U=V$，退出；
   2. 从图中选择满足$\{(u,v):u\in V',v\in V-V'\}$且权值最小的边加入树$T$。

**Kruskal算法**：时间复杂度为$O(|E|\log_2|E|)$，适合边稀疏但点多的图。

1. 树$T=(V',E')$，其中$V'=V,E'=\varnothing$；
2. 循环：
   1. 若$|E'|=|V|-1$，退出；
   2. 从$E-E'$按边权递增选择边，若边加入$T$后不构成回路，则加入，否则舍弃。



#### 最短路径

广度优先搜索可以求无权图的单源最短路径。

单源最短路径的**Dijkstra算法**：时间复杂度$O(|V|^2)$，不适用存在负权边的图。

1. 树$T=(V',E')$，其中$V'$仅包含源点$v_0$，记录$V-V'$中每个点到$v_0$的距离。
2. 循环：
   1. 若$V'=V$，退出；
   2. 从$V-V'$中选出与$V'$距离最短的点$v_i$加入$V'$；
   3. 更新$V-V'$中每个点$v_j$到$v_0$的距离$d_{0j}=\min(d_{0i}+d_{ij},d_{0j})$。

各点间最短路径的**Floyd算法**：时间复杂度$O(|V|^3)$，不适用存在负权环的图。

1. 邻接矩阵表示；
2. 对每个点$v_k$，两层遍历$i,j$，更新距离$d_{ij}=\min(d_{ik}+d_{kj},d_{ij})$。



#### 有向无环图

有向无环图即不存在环的有向图，简称**DAG图**，相较二叉树可以共享子结点。

1. 点表示活动，边体现先后的DAG图称为**顶点表示活动的网络 AOV网**；
2. 点表示时间，边表示活动，边权表示开销的DAG图称为**边表示活动的网络 AOE网**。
   1. AOE网从源点到汇点的所有路径中，具有最大长度的路径称为**关键路径**。
   2. 关键路径可能不止一条，只有关键路径长度的最大值减小，才能减短总时间。

DAG图的**拓扑排序**是点的序列，每个点只出现一次，且不存在从序列右侧点到左侧点的路径。

1. 空点序列$\{v_n\}$；
2. 循环：
   1. $\mathrm{len}\{v_n\}=|V|$，退出；
   2. 选择一个入度为0的点$v$加入$\{v_n\}$，删除$G$中点$v$与所有以$v$为起点的有向边。

邻接表时间复杂度$O(|V|+|E|)$，邻接矩阵时间复杂度$O(|V|^2)$。

1. 每次入度为0的点唯一当且仅当则拓扑排序唯一。
2. 若拓扑排序，则可通过编号使邻接矩阵为上三角矩阵。
