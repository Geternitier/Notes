# 总线与IO



## 1. 总线

### 1.1 概述

计算机的各个部件需要通过线路连接，由于计算机部件层出不穷，网状互联会导致复杂度极高。如今计算机常采用**总线式连接**，即各个部件使用同一条通用传输线路，以**分时共享**的方式通信。

**总线**是计算机组件使用的公共信息传输线路。

1. CPU芯片内部各部件使用的总线称为**内部总线**；
2. CPU和主存、外部设备使用的总线称为**外部总线**。
3. 按总线的使用方式，又可把总线分为**控制**、**地址**、**数据总线**。

常见总线协议有：

1. **工业标准架构 ISA**和**扩展ISA EISA**是最早的总线协议，已淘汰；
   1. 芯片控制DMA，主板DMA控制器，DMA通道有限，CPU参与控制。
   2. 无法即插即用。
2. **视频电子标准协会 VESA**是延伸内部总线，用于显卡的总线协议，已淘汰；
3. **外部设备互联 PCI**是取代ISA和VESA成为占据市场的总线协议，
   1. 与处理器独立，PCI设备主控DMA，CPU仅开始和结束时参与；
   2. 即插即用；
   3. PCI的后继**PCIexpree PCIe**是如今主流的总线协议。
4. **加速图形接口 AGP**是2000年左右用于显卡的接口，已淘汰。
5. **通用串行总线 USB**是专门用于连接外部设备的总线，广泛使用。
6. **SATA**是专门用于硬盘的总线协议，**NVMe**是SSD的主流协议。



### 1.2 工作流程

总线传输的过程，就是对传输权分时共享的分配过程。

#### 总线事务

总线上，主控设备如CPU、DMA控制器称为**主设备**，而内存、外部设备称为**从设备**。

主从设备一次信息交换的过程称为**总线事务**，分为下述阶段：

1. **请求**：主设备请求总线传输权。
2. **仲裁**：总线传输权分配给某个申请者。
3. **寻址**：主设备给定命令和地址启动从设备，总线地址线位数称为**总线寻址能力**。
4. **传输**：主设备和从设备进行数据交换，地址/数据线复用的方式称为**总线复用**。

5. **释放**：主设备撤出总线。

一次总线事务的时间称为**总线周期**。



#### 总线定时

协调主从设备操作顺序的时序规则称为**总线定时**。

1. **同步定时**：使用统一时钟信号来协调发送和接收者。
2. **异步定时**：使用请求和回答信号进行协调。
   1. 全互锁：主设备请求后一定要收到回答后，才撤销请求；主设备撤销请求后，从设备才能撤销回答。
   2. 半互锁：主设备请求后一定要收到回答后，才撤销请求；从设备发出回答后一段时间撤销回答。
   3. 不互锁：主设备请求后一段时间，撤销请求；从设备发出回答后一段时间撤销回答。
3. **半同步定时**：既使用统一时钟，又检测响应信号。
4. **分离定时**：请求过程和回答过程分离，两个过程中主从设备互换。

总线基础时钟信号的频率称为**总线时钟频率**，现代总线一个时钟周期可以传送多次数据，每秒能进行的传输次数称为**总线工作频率**，往往是时钟频率的几倍。



#### 总线传输

类似内存，发送首地址后，连续传送多个连续地址数据的方式称为**突发传输**。

总线的串行和并行传输：

1. 串行：数据按位顺序传输。
2. 并行：多条数据线提供多个位的传输，数据线的条数称为**总线宽度**。

**总线带宽**=**总线宽度**$\times$**总线工作频率**。



### 1.3 总线结构

早期计算机使用共享总线。

1. 所有计算机组件都连接在一条共享总线上，称为**单总线结构**。
2. 后来为了提高主存的访问速度，在CPU和主存间架设专线，称为**双总线结构**。
3. 再后来，为了提高吞吐能力，架设外部设备到主存的DMA总线，称为**三总线结构**。

由于共享总线的性能瓶颈无法解决，诞生了分层总线结构。

1. 将CPU、主存和GPU连接在高速总线上，称为**北桥**；
2. 外部设备设备连接在低速总线上，称为**南桥**；
3. 北桥设置**内存控制器**，南桥设置**IO控制器**，控制总线传输；
4. 内存控制器和IO控制器之间通过**桥间总线**连接。

现代随着技术提升，北桥的功能逐渐被集成到CPU内部，CPU与主存和GPU直连，通过IO控制器连接低速设备。

1. CPU访存经内存控制器，通过主板走线直接传递给内存条；
2. CPU访问的PCIe控制器包含一定数量的PCIe通道：
   1. 多数通道通过主板走线直连最靠近CPU的GPU；
   2. 少数通道通过主板走线直连SSD；
   3. 少数通道连接主板芯片组，也就是IO控制器；
3. 对应于功能特化的计算机而言，IO控制器也可以集成到CPU中。



## 2. IO设备



### 2.1 概述

**输入/输出 IO**就是CPU和外部设备之间的通信。

常见外部设备：

1. 输入设备：键鼠、手柄
2. 输出设备：显示器、打印机
3. 外部存储器：机械硬盘、光盘、固态硬盘



### 2.2 IO接口

**IO接口**，即IO控制器，负责控制CPU和外部设备的通信，其功能包括：

1. 通信控制：电信号格式转换、信号时序控制；
2. 设备选择：将CPU给出的地址转换为设备选择信号；
3. 控制代理：将CPU的命令翻译成外部设备的控制信号；
4. 数据缓冲：暂存传输的数据，避免因设备不同步而丢失数据。

IO接口的线路传输内容：

1. 地址线：访问的IO端口地址；
2. 数据线：数据、状态信息、控制信息和中断类型号；
3. 控制线：控制信号、中断请求和响应信号、总线仲裁信号和设备握手信号。

**IO端口**指CPU可通过IO接口直接访问的设备寄存器，通常被编入CPU的地址空间。

1. 独立编址：I/O端口的地址空间独立于主存地址空间。
2. 统一编址：将I/O端口的地址映射到主存地址空间中。



### 2.3 IO方式

IO方式指CPU、内存和外部设备之间协同合作的方式。

1. **程序查询**：
   1. 设置**数据端口**，即数据缓冲寄存器；
   2. 设置**状态端口**，即设备状态寄存器；
   3. CPU先查询状态，再决定传输数据或等待。
   4. **独占查询**指CPU轮询忙等，**周期查询**指CPU周期性查询设备状态。
2. **程序中断**：
   1. 进程发起IO时，启动外设并进入阻塞状态；
   2. 外设数据就绪后，向CPU发起中断请求；
   3. CPU响应后，保护现场，转入中断服务程序，完成数据传输；
   4. CPU恢复现场，返回断点继续执行。
3. **直接内存访问 DMA**：由DMA控制器负责外设数据到内存的传输
   1. CPU向IO控制器发出IO命令，然后处理其他任务；
   2. DMA控制器控制数据通过IO控制器写入内存；
   3. 写入完成后，DMA控制器向CPU报告操作完成。
   4. 早期DMA控制器和IO控制器独立，现在DMA控制器往往是IO控制器的子模块。

DMA访存方式：

1. 停止CPU访存：向CPU发送停止信号，完成整块数据传输后恢复。
2. 周期挪用：
   1. CPU不在访存，DMA直接访存；
   2. CPU和DMA同时请求访存，则DMA先访存；（I/O不立即访存会丢失数据）
   3. CPU在访存，等待存取周期结束后访存。
3. 交替访存：将CPU的时钟周期分为CPU访存和DMA访存两个时间片。



中断过程的考点：

1. 硬件完成：
   1. 关中断
   2. 保存断点（PC和PSW）
   3. 中断服务程序寻址。
2. 中断服务程序完成：
   1. 保存现场和屏蔽字，开中断
   2. 执行中断服务程序
   3. 关中断，恢复现场和屏蔽字，开中断
3. 中断屏蔽位的1表示屏蔽，0表示可以正常请求。多个中断屏蔽位形成中断屏蔽字。



## 3. IO系统



### 3.1 IO软件

涉及IO的软件可分为四个层次：

1. 用户软件：直接调用OS提供的库函数进行IO操作；
2. 设备独立软件：OS调用驱动软件，向用户提供操作接口；
3. 设备驱动软件：通过IO控制器控制设备完成操作；
4. 中断处理软件：处理设备完成操作后发起的中断。



### 3.2 设备独立软件

**设备独立软件**是OS调用驱动软件，向用户提供操作接口的子系统，主要进行下述工作。

1. 地址映射：OS将设备映射到地址空间便于访问；
2. 缓冲管理：在映射的地址空间中设置缓冲区，管理设备数据传输；
3. 用户接口：向用户软件提供设备操作接口；
4. 设备分配：将设备分配给用户软件使用。



#### 缓冲区

缓冲区用于缓和CPU和外设速度不匹配的问题，提供并行性。

1. 单缓冲：开设一个缓冲区，CPU和IO控制器互斥读写；
2. 双缓冲：开设两个缓冲区，单缓冲区互斥读写，不同缓冲区可并行；

3. 循环缓冲：开设一组缓冲区，每个缓冲区有指向下一个缓冲区的指针，构成循环；

4. 缓冲池：开设一组缓冲区，统一管理和分配。



#### 设备分配

1.3节提到，CPU划分不同的总线通道，通道连接各自的IO控制器，不同IO控制器又会连接多个设备。于是OS会组织下述数据结构来管理设备：

1. **通道控制表 CHCT**：每个通道一张CHCT，记录通道信息下属的IO控制器；
2. **控制器控制表 COCT**：每个IO控制器一张COCT，记录控制器信息和下属设备；
3. **设备控制表 DCT**：每个设备一张DCT，记录设备信息，包括
   1. 设备类型：独占、共享、虚拟（通过软件调度使独占设备共享化）
   2. 设备标识符：唯一标识
   3. 设备状态：忙、闲
   4. 控制器表指针等
4. **系统设备表 SDT**：所有设备的全局索引。
5. **逻辑设备表 LUT**：用户看到的是逻辑设备，由LUT映射为实际设备。

相应的，分配设备时，会**先分配设备，再分配控制器，最后分配通道**，依次查表。

设备分配算法通常采用FCFS，并允许高优先级插队。

1. 进程发起IO请求后立即阻塞的方式称为**安全分配方式**，因为不请求额外资源避免死锁；
2. 进程发起IO请求后继续运行的方式称为**不安全分配方式**。



#### 假脱机

由于打印机等外部设备的速度比CPU慢太多，CPU等待打印机打印会占用大量CPU时间，因此诞生了**假脱机 SPOOLing**技术。

1. 输出时，CPU先把数据写到磁盘，再由专门的输出进程将磁盘中的数据交付给输出设备；
2. 输入时，由专门的输入进程将输入设备的数据写到磁盘，CPU需要时再读取。
3. 称磁盘中用于缓冲的区域为**输入井/输出井**，控制输入和输出的程序为**井管理程序**。

假脱机技术能将独占设备改造成共享设备，也可以将一台物理设备抽象为多个逻辑设备。



## 4. 文件系统

### 4.1 概述

**文件**是外部存储中存储数据的基本单元。

**文件系统**是设备独立软件的一部分，向用户提供文件访问接口，把逻辑文件映射为物理存储，并通过外存驱动程序管理文件数据。



### 4.2 文件结构

#### 逻辑结构

逻辑文件的一般数据结构：

1. 文件元数据，包含：
   1. 名称、类型
   2. 位置、大小
   3. 访问控制策略：权限类型总数=访问类型数$\times$用户类型数
   4. 创建时间和修改时间
2. 文件数据。
   1. 流式：连续字符流；
   2. 记录式：由多条记录组成。

若记录式文件每个记录长度相同，称为**定长记录文件**，否则为**变长记录文件**。

1. 顺序文件：记录按线性顺序排列，分为按存入时间序的串结构和按关键字序的顺序结构；
2. 索引文件：文件建立索引表，表项「记录起始地址｜长度」。
3. 索引顺序文件：文件分组，索引表记录每个组，组内文件顺序。
4. 直接文件：又称散列文件，文件地址由关键字散列。



#### 物理结构

1. 顺序文件：逻辑连续的信息存在相邻的物理块，也称连续文件。
2. 连接文件：使用连接字来表示文件中各个物理块之间的先后次序。
   1. 隐式：文件目录给出首个物理块位置，每一块用连接字指出下一个块位置。
   2. 显式：使用文件分配表记录每个物理块位置。
3. 索引文件：文件建立索引表，表项「逻辑记录号｜存储位置 或 下一级索引表位置」；
4. 直接文件：又称散列文件，文件地址由关键字散列。



#### 文件目录

**文件控制块 FCB**是OS用于管理文件元数据和控制信息的数据结构。

1. **索引节点 inode**是UNIX系OS简化的FCB，不包含文件名；
2. 一般**文件目录**的目录项就是FCB；
3. UNIX**文件目录**的目录项「文件名｜索引节点号」。

文件目录用于按名检索、存取、共享文件，常用线性表或散列表实现。

1. 单级目录：目录项为FCB；
2. 二级目录：主目录的目录项为单级目录的位置；
3. 树形目录：每个目录的目录项为单级目录或者FCB。
4. 无环图目录：在树形目录下，允许不同目录共享子目录或子文件。
   1. 硬链接：基于索引，文件信息存放在索引中，新增硬链接即新增索引中链接记数；
   2. 软链接：被链接文件的路径。



### 4.3 文件系统

#### 结构

1. 用户接口：接受系统调用，进行语法检查，进入逻辑文件控制子系统
2. 逻辑文件控制子系统：根据文件路径名，搜索文件目录，建立活动文件表，根据文件结构和存取方法，把逻辑记录转换成相对物理块号和块内相对地址
3. 文件保护子系统：识别调用者身份，验证存取权限，判定本次文件操作的合法性
4. 物理文件控制子系统：实现缓冲区管理，根据物理结构，将对应相对物理块号转换为实际物理块号，负责文件存储空间的分配，输入/输出控制系统调用形式
5. 输入/输出控制子系统：执行具体的物理块输入/输出操作



#### 外存管理

分配：

1. 连续分配：存放在辅存空间连续存储区中（连续的存储块号）
   - 优点是顺序访问速度快，管理简单
   - 为了获得足够大的连续存储区，需要定时进行碎片整理
2. 非连续分配：动态分配给若干扇区或簇，不要求连续
   - 辅存空间管理效率高，便于文件动态增长和收缩

空闲块管理：

1. 连续分配：空闲表
2. 非连续分配：空闲链表
   - 位示图：使用若干字节构成一张表，表中每一字位对应一个物理块，字位的顺序和块的相对次序一致，字位为1表示相应块已占用，字位为0表示该块空闲。
   - 成组链接法（将空闲块分组，每组为一个链表，空闲盘块号栈）



#### 虚拟文件系统

屏蔽不同文件系统差异，提供统一操作接口

- 超级块：包含文件系统信息
- 索引结点
- 目录项
- 文件对象
