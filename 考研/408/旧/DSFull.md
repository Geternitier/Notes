## 0. 概念

### 0.1 数据结构

1. **数据**是信息的载体，能被计算机程序识别和处理的符号集合。
2. **数据元素**是数据的基本单位。
3. **数据类型**是一类数据元素的集合和定义在此集合上的一组操作的总称。
   - **原子类型**是值不可再分的数据类型；
   - **结构类型**是值可以再分解为若干分量的数据类型；
   - **抽象数据类型 ADT**是一个数据类型及定义在该数据类型上的一组操作。
4. 数据元素相互之间的关系称为**数据结构**，包括**逻辑结构**、**存储结构**和**数据运算**。
   1. 逻辑结构包括**线性结构**、**非线性结构**，存储结构包括**顺序**、**链式**、**索引**、**散列**。
   2. 数据运算的定义取决于逻辑结构，实现取决于物理结构。




### 0.2 算法

#### 概念

算法是对特定问题求解步骤的一种描述。

- 算法的五个重要特性：
  - 有穷性：有穷步数，有穷时间
  - 确定性：相同输入，相同输出
  - 可行性：可由已定义的有限次运算实现
  - 输入
  - 输出

- 好的算法的目标：
  - 正确性
  - 可读性
  - 健壮性：能对非法输入进行处理
  - 高效率、低存储



#### 度量

1. 时间复杂度：算法中所有语句的频度和的数量级。
2. 空间复杂度：算法所需存储空间。



## 1. 线性表

### 1.1 线性表基础

#### 定义

1. 线性表：具有相同数据类型的$n$个数据元素的有限序列。
   - $n$为表长，当$n=0$，该表为空表。
2. 基本操作：
   - 初始化/销毁
   - 求表长
   - 判空
   - 按值查找位
   - 按位查找值
   - 插入/删除



#### 顺序存储

1. 线性表的顺序存储，又称顺序表。
   - 用一组地址空间连续的存储单元依次存储线性表中的数据元素。
2. 基本操作：
   - 按值查找位：遍历表，时间复杂度$O(n)$。
   - 按位查找值：随机访问，时间复杂度$O(1)$。
   - 插入/删除：执行操作并移动操作位置后的所有元素，时间复杂度$O(n)$。
3. 评价：只存储数据元素，存储密度高，但需要连续存储空间，不灵活。



#### 链式存储

1. 单链表：通过一组链表结点存储线性表。

   - 每个链表结点包含数据元素与后继指针，表尾元素后继为空。

   - 头指针：链表的起始地址。
     - 头结点：指针指向第一个数据元素。
     - 有头结点时，头指针指向头结点，头结点指针指向空表示链表为空。
     - 无头结点时，头指针为第一个数据元素，为空时表示链表为空。
   - 基本操作：
     - 查找、求表长：遍历表，时间复杂度$O(n)$。
     - 插入/删除：先查找$O(n)$后操作$O(1)$，时间复杂度$O(n)$。
   - 循环单链表：表尾元素后继为头结点。
     - 常设尾指针，此时头插与尾插时间复杂度均为$O(1)$。

2. 双链表：通过一组链表结点存储线性表。

   - 每个链表结点包含数据元素、前驱指针与后继指针，表头元素前驱为空，表尾元素后继为空。
   - 循环双链表：表头元素前驱为表尾元素，表尾元素后继为头结点。

3. 静态链表：用顺序存储的方式来存储链表，不同于顺序表的是，每个结点额外存储下一个元素的位置。



#### 数组

1. 具有相同数据类型的$n$个数据元素的有限序列，线性表的推广。
   - 每个数据元素称为一个数组元素
   - 每个元素的序号称为该元素的下标
2. 多维数组：元素为数组的数组。
   - 特殊矩阵压缩存储：
     - 上/下三角矩阵：按行或列序依次存储上/下三角元素到一维数组中。
     - 对称矩阵：转化为上/下三角矩阵。
     - 三对角矩阵：非零元素集中在以主对角线为中心的3条对角线上的矩阵。
       - 按行或列序依次存储到一维数组中。
     - 稀疏矩阵：非零元素数远小于矩阵元素数。
       - 三元组存储：$(行,列,值)$。也需要保存矩阵的行数、列数(和非零元素数)。
       - 十字链表：$(行,列,值,行下一个非零,列下一个非零)$，并用数组存储每行每列第一个非零元素的结点指针。



#### 字符串

1. 字符串，简称串，零个或多个字符组成的有限序列。
   - 长度为0的串称为空串。
   
2. 模式匹配：查找子串位置。
   
   KMP算法：使用最长公共前后缀进行匹配。
   
   - 设原字符串为$s$，定义一个和原字符串相同长度的数组next。
   
   - 计算next数组：数组中每个位置的值表示原字符串对应位置子串与自身的最大匹配位置。
   
     - $\mathrm{next}[0]=-1$，设一个变量$j$表示遍历位置前一个数的匹配位置，初始化为$-1$。
     - 遍历每个位置，计算最大匹配位置。
   
   - ```C++
     void getNext (int* next, const string& s){
         next[0] = -1;
         int j = -1;
         for(int i = 1;i < s.size(); i++){
             while(j >= 0 && s[i] != s[j + 1]) {
                 j = next[j];
             }
             if(s[i] == s[j + 1]) {
                 j++;
             }
             next[i] = j;
         }
     }
     ```



### 1.2 栈

#### 定义

1. 栈：只允许在一端进行插入/删除的线性表。
   - 栈顶：线性表允许进行插入/删除的端点。
   - 栈底：线性表不允许进行插入/删除的端点。
2. 基本操作：
   - 初始化/销毁
   - 判空
   - 压栈/出栈
   - 读栈顶元素
3. 卡特兰数公式：当$n$个不同元素按一定顺序压栈，出栈序列的排列数为$\frac1{n+1}C_{2n}^n$。



#### 存储

1. 使用顺序表依次存储栈中元素，并记录栈顶元素位置。
   - 共享栈：将两个栈的栈底设为一个顺序存储空间的两端，两个栈顶向中间延伸。
2. 使用链表存储栈。



#### 应用

1. 括号匹配、表达式求值
2. 递归算法非递归化
3. 函数调用



### 1.3 队列

#### 定义

1. 队列：只允许在一端进行插入、另一端进行删除的线性表。
   - 队头：允许删除的一端。
   - 队尾：允许插入的一端。
2. 基本操作：
   - 初始化/销毁
   - 判空
   - 入队/出队
   - 读队头元素
3. 双端队列：只允许在两端进行插入/删除的线性表。
   - 输入受限：一端插入，两端删除
   - 输出受限：两端插入，一端删除



#### 存储

1. 使用顺序表依次存储队列中元素，记录队头和队尾位置。
   - 已出队位置空间浪费$\rightarrow$循环队列
   - 循环队列：队头/尾到顺序表上限后到0位继续操作。
     - 判满与判空的三种方法
       - 计数队列中元素数
       - 队尾=队头即空，(队尾+1)%表长=队头即满，牺牲一个存储位置
         - 此时队尾指针指向队尾元素的后一个位置。
       - 使用一个标志，当删除后队尾=队头即队空，插入后队尾=队头即队满
2. 队列的链式存储也称链队列。



#### 应用

1. 层次遍历
2. 缓冲区
3. 资源的队列管理



## 2. 树

### 2.1 树基础

#### 树

1. 树：$n$个结点的有限集合。当$n=0$，称为空树。且一棵非空树满足：
   - 有且仅有一个称为根的结点；
   - 非根结点可分为互不相交的有限集合，每个集合本身又是一棵树，并且是根的子树。
2. 术语：
   - 祖先、子孙：某个结点$K$到根的路径上的所有其他结点为$K$的祖先，$K$是它们的子孙。
   - 父/母亲、孩子：某个结点$K$到根的路径上离$K$最近的其他结点为其父/母亲，$K$是它们的孩子。
   - 兄弟、堂兄弟：父/母亲为同一个结点的结点称为兄弟，父/母亲为同一层结点的结点称为堂兄弟。
   - 度：一个结点的孩子数称为该结点的度。树中结点的最大度数称为树的度。
   - 分支结点、叶结点：度为0的结点为叶结点，否则为分支结点。
   - 层次、深度/高度：根为1层，孩子为2层，类推。
     - 树的深度/高度为最大层数。
     - 结点的高度是以其为根的子树的高度。
   - 有序树和无序树：结点的左右子树有顺序、不能互换的树为有序树，否则为无序树。
   - 路径：两个结点之间经过的结点序列。路径长度为经过的边的长度。
3. 计算性质：需要的话现场算即可
   - 结点数为所有结点度数+1（子结点数+根结点）
   - 度为$m$的树中第$i$层上至多有$m^{i-1}$个结点（等比数列）
   - 高为$h$的$m$叉树至多有$\frac{(m^k-1)}{m-1}$个结点（等比数列）
   - 度为$m$、具有$n$个结点的树的最小高度为$[\log_m(n(m-1)+1)]+1$
   - 度为$m$、具有$n$个结点的树的最大高度为$n-m+1$。
   - 高度$h$、度为$m$的树至少有$h+m-1$个结点



#### 存储

1. 双亲表示法：使用数组存储结点，每个结点记录其值与双亲的下标。
2. 孩子表示法：每个结点的孩子用一个线性单链表存储。
3. 左孩子右兄弟表示法：第一个孩子的根作为左子结点，下一个兄弟的根作为右子结点。
   - 树、森林可使用左孩子右兄弟表示法转化为二叉树。



### 2.2 二叉树

#### 定义

1. 二叉树中不存在度大于2的结点，且二叉树的子树有左右之分。
   - 和度为2的有序树的区别：当一个结点只有一个子结点，二叉树仍然区分左和右。
2. 特殊二叉树：
   - 满二叉树：高度为$h$，且有$2^h-1$个结点的二叉树。
     - 按层序为结点编号，则$i$结点的父结点为$[\frac i2]$，左子结点为$2i$，右子结点为$2i+1$。
   - 完全二叉树：高度为$h$、有$n$个结点的二叉树，当它的每个结点都与高度为$h$的满二叉树中编号为$1\sim n$的结点一一对应，称其为完全二叉树。
     - $i\le[\frac n2]$为分支结点，否则为叶结点。
     - 叶结点只会在最高的2层。
     - 度为1的结点最多有1个，它的子结点一定是左子结点，此时$n$为偶数。
     - 结点$i$在$[\log_2n]+1$层（或$\log_2(n+1)$向上取整，$\log_2n$向上取整可能是错的）
   - 二叉排序树：任意结点左子树上所有结点的值小于原结点的值小于结点右子树上所有结点的值。
   - 平衡二叉树：任意结点的左右子树高度差的绝对值不大于1，也称AVL树。
   - 正则二叉树：树中只有度为0或2的结点。
3. 计算性质：设度为$0,1,2$的结点数为$n_0,n_1,n_2$。
   - 非空二叉树的叶结点数等于度为2的结点数+1：$n_0=n_2+1$
4. 遍历：
   - 先序：从根结点开始，对每个结点，按照根$\rightarrow$左子树$\rightarrow$右子树的顺序进行遍历。
   - 中序：从根结点开始，对每个结点，按照左子树$\rightarrow$根$\rightarrow$右子树的顺序进行遍历。
   - 后序：从根结点开始，对每个结点，按照左子树$\rightarrow$右子树$\rightarrow$根的顺序进行遍历。
     - 上述三种遍历可以使用递归/栈来实现。
   - 层序：逐层从左到右遍历。
     - 使用队列实现。
5. 使用遍历序列构造二叉树：
   - 中序+先序
   - 中序+后序
   - 中序+层序
   - 其余组合均无法唯一确定一棵二叉树。



#### 存储

1. 顺序存储：按照满二叉树结点编号位置存储二叉树结点，不存在的结点置0。

2. 链式存储。

   - 在含有$n$个结点的二叉链表中含有$n+1$个空链域$\rightarrow$线索二叉树。

3. 线索二叉树：添加左右标记位，记录是否有左右子树。

   若无左子树，则左指针指向前驱结点，若无右子树，右指针指向后继结点。

   - 构建：在遍历过程中记录前驱结点，若无左指针则添加，若前驱无右指针则添加。
   - 先序、中序、后序下查找前驱和后继。



### 2.3 应用

#### 哈夫曼树

1. 路径：从树上一个结点到另一个结点间的分支。

   路径长度：路径上的分支数。

   权：结点被赋予的数值。

   结点的带权路径长度：从树的根到一个结点的路径长度和该结点权的乘积。

   树的带权路径长度：树中所有叶结点的带权路径长度之和。

2. 哈夫曼树：含有n个带权叶结点的、带权路径长度最小的二叉树。

   - 构造哈夫曼树：
     1. 将n个结点视为n个仅含一个结点的树。
     2. 构造一个新结点，选取根的权值最小的两棵树作为其左右子树，新结点的权为两树根权之和。
     3. 重复2直至只剩下一棵树。

3. 哈夫曼编码：利用二叉树来设计二进制前缀编码。

   - 固定长度编码：每个字符用相等长度二进制表示。
   - 可变长度编码：不同字符可以用不同长度二进制表示。
     - 前缀编码：没有一个编码是其他编码的前缀。

   示例：0表示A，10表示B，110表示C，111表示D。

   - 使用字符出现的频度作为权，将每个字符作为结点构建哈夫曼树，进行编码。



## 3. 图

### 3.1 基础

#### 概念

1. 图：$G=(V,E)$，其中$V$为非空有限点集，$E$为边集。

   - $|V|$表示图中点的个数，$|E|$表示边数。
   - 子图：若$G'=(V',E')$中$V'\sub V,E'\sub E$，则称$G'$为$G$的子图。
     - 若$V(G')=V(G)$，则称$G'$为$G$的生成子图。
   - 有向图：边具有方向。
   - 无向图：边不具有方向。
   - 简单图：不存在重复边与顶点到自己的边的图。反之为多重图。
   - 完全图：每个点之间都具有边。
     - 一个有$n$个顶点的无向图，$|E|\le \frac12n(n-1)$，若取等，它是无向完全图。
     - 一个有$n$个顶点的有向图，$|E|\le n(n-1)$，若取等，它是有向完全图。
   - 有权图：边上带有权值的图，也称为网。
   - 稀疏图：边数很少的图，反之称为稠密图。

2. 顶点$v$的度：

   - 无向图：与顶点相连的边的总数，记为$TD(v)$。
   - 有向图：入度$ID(v)$为其入边数、出度$OD(v)$为其出边数。度为$TD(v)=ID(v)+OD(v)$。
     - 有向图所有点的入度和等于所有点的出度和等于边数。
   - 在有$n$个顶点的图中，$|E|$等于所有顶点度数的和的二分之一。
   - 有向树：一个顶点的入度为0，其余顶点的入度为1的有向图。

3. 路径：一系列顶点$P=i_1,...i_k$，$\forall 1\le j\le k$，边$(i_j,i_{j+1})$在图G中，称$P$为$G$中一条$i_1$到$i_k$的路径。

   回路：第一个顶点与最后一个顶点相同的路径。

   - 路径长度：路径上的边数。

   - 简单路径：除了首尾顶点外所有顶点不重复。
   - 简单回路：首尾为相同顶点的简单路径。

   距离：图中两个顶点间最短路径的长度。若不存在两个顶点间的路径则为$\infin$。

4. 连通：在无向图中，如果两点间存在路径，则两点连通。

   连通图：在无向图中，若任意两顶点连通，则称该图为连通图。

   连通分量：无向图的极大连通子图称为连通分量。

   强连通：有向图中，若顶点对$i,j$间存在$i$到$j$和$j$到$i$的路径，则这两个顶点强连通。

   强连通图：有向图中所有顶点对间强连通，则该图为强连通图。

   强连通分量：有向图的极大强连通子图为其强连通分量。

5. 生成树：包含连通图中所有顶点的极小连通子图。

   - 最小生成树：对一个带权连通无向图，权值之和最小的生成树。
     - 若图存在权值相同的边，则最小生成树可能不唯一。
     - 图的最小生成树的权值之和是唯一的。
     - 最小生成树的边数为顶点数减一。

#### 表示

1. 邻接矩阵：图$G=(V,E)$的邻接矩阵为$A(i,j)$，$\lang i,j\rang\in E$则$A(i,j)$为1，否则为0。
   - 无向图的邻接矩阵为对称矩阵。
   - 有向图中，第i行的累加为点i的出度，第i列的累加为点i的入度。
   - 对加权图，将1替换为其权重，0替换为∞，此外，还需要记录各顶点信息的表与当前的边数。
2. 邻接表：顺序存储顶点结点，以每个顶点结点为首结点建立单链表，记录与其相连的顶点。
   - 当边数较少，邻接表减少了存储的需求。
   - 对有向图，邻接表记录出边，而记录入边的为逆邻接表。
3. 邻接多重表：顺序存储顶点结点，顶点结点连接边结点构成链表。
   - 顶点结点记录该顶点第一条边。
   - 边结点记录两个顶点与它们各自的下一条边。
     - 用于无向图
4. 十字链表：顺序存储顶点结点，顶点结点连接边结点构成链表。
   - 顶点结点记录该顶点第一条入边和出边。
   - 边结点记录入顶点和出顶点、入顶点的下一条入边、出顶点的下一条出边。
     - 用于有向图
5. 图的基本操作：
   - 判断边$\langle x,y\rangle$是否存在
   - 列出某结点连接的其他顶点
   - 插入/删除顶点
   - 插入/删除边



### 3.2 计算

#### 遍历

1. 广度优先
2. 深度优先



#### 应用

1. 最小生成树

   - 基本性质：带权连通无向图$G=(V,E)$，$U$为顶点集$V$的一个非空子集，若$(u,v)$是一条具有最小权值的边，其中$u\in U,v\in V-U$，则必存在一棵包含边$(u,v)$的最小生成树。

   Prim算法：连通图$G=(V,E)$，其最小生成树$T$。

   1. 初始化：向空树$T$中添加图的任一顶点。
   2. 循环：从图中选择满足$\{(u,v):u\in U,v\in V-U \}$且权值最小的边加入树$T$。

   - 时间复杂度为$O(|V|^2)$，适合边稠密的图。

   Kruskal算法：连通图$G=(V,E)$，其最小生成树$T=(U,E_T)$。

   1. 初始化：$U=V,E_T=\varnothing$。
   2. 循环：按$G$的边权递增顺序从$E-E_T$中选择一条边，若该边加入$T$后不构成回路，则将其加入，否则舍弃。直到$E_T$中含有$n-1$条边。

2. 单源最短路径，Dijkstra算法：求图中某一顶点到其他各顶点的最短路径。

   1. 初始化：集合$S=\{0 \}$，记录$V-S$中每个顶点到源点$v_0$的距离。
   2. 从顶点集合$V-S$中选出与$v_0$距离最短的点$v_j$。
   3. 更新从$v_0$出发到集合$V-S$上每个顶点的距离为$v_j$到其距离和原距离的较小者。
   4. 重复2和3，直到所有的顶点处于$S$中。

   - 边上带有负的权值时，Dijkstra算法不适用。

3. 各顶点之间最短距离，Floyd算法：

   1. 初始化：将图表示为邻接矩阵。
   2. 对每个结点$k$，两层遍历结点$i,j$，比较$k$到两结点$i,j$距离与$i,j$现距离。
   3. 重复2。

4. 有向无环图：不存在环的有向图，相较二叉树存储可以共享子结点，节省存储空间。简称DAG图。

   - 用有向无环图表示工程，顶点表示活动，体现活动必须的先后关系。这称为顶点表示活动的网络，简称AOV网。

5. 拓扑排序：有向无环图的顶点序列，每个顶点只出现一次，不存在从后续结点到序列前部结点路径。

   - 过程：每次选择一个入度为0的顶点并输出，删除该顶点与所有以它为起点的有向边。
     - 每次检测入度为0的顶点都唯一，则拓扑排序唯一。
   - 邻接表拓扑排序时间复杂度$O(|V|+|E|)$，邻接矩阵拓扑排序时间复杂度$O(|V|^2)$。
     - 若邻接矩阵为三角矩阵则拓扑排序唯一，反之不一定成立。

6. 用边表示活动的网络，AOE网：顶点表示时间，有向边表示活动，边权表示开销。

   - 关键路径：从源点到汇点的所有路径中，具有最大长度的路径。



## 4. 查找



### 4.1 概念

1. 查找：在数据集合中寻找满足某种条件的数据元素的过程。

2. 查找表：用于查找的数据集合。

   - 静态查找表：只读的查找表。常用顺序查找、二分查找、散列查找。

   - 动态查找表：需要动态插入或删除的查找表。常用二叉排序树、散列查找。

3. 关键字：数据元素中唯一标识该元素的某个数据项的值。

   查找长度：查找需要比较关键字次数。

   平均查找长度，ASL：所有查找过程中查找长度的平均值。



### 4.2 查找算法

#### 线性查找

1. 顺序查找：适用于顺序表和链表。
   - 对无序线性表，查找成功的平均长度为$\frac{n+1}2$，查找失败的平均长度为$n+1$。
   - 对有序线性表，可以通过比较来提前得知查找失败。
2. 二分查找：仅适用于有序顺序表，不适用于链表。
   - 查找成功的平均长度为$\frac{n+1}{n}\log_2(n+1)-1$。
3. 分块查找：又称索引顺序查找。
   - 将查找表分为多个块内元素可以无序，块间有序的查找块。
   - 建立索引表，记录每个块的最大值和第一个元素的地址。索引有序排列。
   - 先查索引，后查块。



#### 树形查找

1. 二叉排序树

   - 查找：从根结点开始逐层向下比较。
     - 查找效率：取决于树的高度。平衡时为$O(log_2n)$，极不平衡时为$O(n)$。
   - 插入：递归
     1. 若原二叉排序树为空，直接插入。
     2. 若关键字小于根节点，插入左子树，否则插入右子树。
   - 构造：从空树开始依次插入元素。
   - 删除：
     - 若为叶结点，直接删除。
     - 若只有一棵左子树或右子树，则让子树替代该结点位置。
     - 若有左右两棵子树，则让其后继或前驱替代其位置，再删除其后继或前驱的原本结点。
2. 二叉平衡树

   - 结点的平衡因子：左子树和右子树的高度差，只可以是$-1,0,1$。

   - 插入：按二叉排序树的方式插入，检查插入路径上的结点，对以离插入结点最近的，平衡因子绝对值大于0的结点为根的子树（最小不平衡子树）进行调整。

     - LL平衡旋转（右旋）：

       - 原因：结点A左子结点B的左子树插入结点，A的平衡因子由1变成2。

       - 过程：B取代A，A成为B的右子结点，B原本的右子树成为A的左子树。

     - RR平衡旋转（左旋）：

       - 原因：结点A右子结点B的右子树插入结点，A的平衡因子由-1变成-2。

       - 过程：B取代A，A成为B的左子结点，B原本的左子树成为A的右子树。

     - LR平衡旋转（先左后右双旋）：

       - 原因：结点A左子结点B的右子树插入结点，A的平衡因子由1变成2。
       - 过程：先将B的右子结点C左旋到B，再将C右旋到A。

     - RL平衡旋转（先右后左双旋）：

       - 原因：结点A右子结点B的左子树插入结点，A的平衡因子由-1变成-2。
       - 过程：先将B的左子结点C右旋到B，再将C左旋到A。

   - 构造：从空树开始依次插入元素。

   - 删除：按二叉排序树的方式删除。找到最小不平衡子树进行调整。然后向根节点逐层回溯检查。
3. 红黑树：满足一定红黑性质的二叉排序树。

   - 红黑性质：
     - 每个结点是红的或黑的。
     - 根结点是黑的。
     - 叶结点都是黑的。引入$n+1$个外部叶结点，使得每个内部结点的左右子结点非空。
     - 不存在两个相邻的红结点。
     - 对每个结点，从该结点到任意一个叶结点的简单路径上，所含黑结点的数量相同。
   - 红黑树的性质：
     - 从根结点到叶结点的最长路径不大于最短路径的2倍。
     - 有$n$个内部结点的红黑树的高度$h\le2\log_2(n+1)$。
   - 插入：
     1. 按二叉排序树的方式插入，并设该结点为红色。
     2. 若其为根节点，则将其改为黑色，结束。
     3. 若其父结点为黑色，结束。
     4. 若其叔结点为红色，则将父结点和叔结点都改为黑色，将爷结点改为红色。然后将爷结点作为新结点进行循环调整。
     5. 其叔结点为黑色：
        - 该结点为爷结点的左子结点的左子结点：LL，并交换父结点和爷结点的颜色
        - 该结点为爷结点的左子结点的右子结点：LR，并交换父结点和爷结点的颜色
        - 该结点为爷结点的右子结点的左子结点：RL，并交换父结点和爷结点的颜色
        - 该结点为爷结点的右子结点的右子结点：RR，并交换父结点和爷结点的颜色
   - 删除
4. B树：$m$阶B树是所有结点的平衡因子均等于0的$m$路平衡查找树。

   - m阶B树满足的特性：
     - 树中每个结点至多有$m$棵子树，即至多有$m-1$个关键字。
     - 非叶根结点至少有2棵子树，即至少有1个关键字。
     - 除根结点以外的所有非叶结点至少有$[\frac m2]$棵子树，即至少有$[\frac m2]-1$个关键字。
     - 非叶结点结构：$n,P_0,K_1,P_1,....K_n,P_n$，$K_i$为关键字，$P_i$为指针。
     - 所有叶结点都是外部结点，在同一层，实际不存在。
   - 查找：多路比较关键字。
   - 高度：对一棵有$n$个关键字，高度为$h$、阶数为$m$的B树：
     - $n\le m^h-1,h\ge\log_m(n+1)$
     - $h\le\log_{[\frac m2-1]}\frac{n+1}2+1$
   - 插入：定位和插入，如果结点关键字多于$m-1$，则需要进行分裂。
     - 分裂：$[\frac m2]$位置的关键字插入父结点，其右的关键字作为新结点。
   - 删除：定位和删除，如果结点关键字少于$[\frac m2]-1$，则需要进行合并。
     - 合并：如果兄弟结点关键字多于$[\frac m2]-1$，则调整其关键字进入父结点，原父结点中关键字进入原结点。否则合并父结点中关键字作为新结点。
5. B+树
   - m阶B+树满足的特性：
     - 树中每个分支结点至多有$m$棵子树。
     - 非叶根结点至少有2棵子树，其他分支结点至少有$[\frac m2]$棵子树。
     - 结点的子树个数和关键字个数相等。
     - 所有叶结点包含全部关键字并指向相应记录的指针。
     - 叶结点将关键字按大小排列并且相邻叶结点按大小顺序相互连接，支持顺序查找。
     - 所有分支结点仅包含其子结点中关键字的最大值和指向子结点的指针。



#### 散列查找

1. 散列函数：把查找表中的关键字映射为对应地址的函数。

   散列表：根据关键字直接进行访问的数据结构。

   - 散列函数定义域包含全部关键字，值域依赖于散列表大小。
   - 散列函数计算出的地址应尽可能均匀分布、减少冲突。
   - 散列函数应尽量简单，计算时间短。

2. 常用散列函数：

   - 直接定址：取关键字的某个线性函数值$H(x)=ax+b$。
   - 除留余数：取一个不大于表长但接近表长的质数$p$，取$H(x)=x\mod p$
   - 数字分析：$r$进制数的$r$个数码在各位上出现的频率不相同，则选取数码分布较平均的位进行散列。
   - 平方取中：取关键字的平方值的中间几位。

3. 处理冲突的方法：

   - 开放定址：空闲地址向非同义词开放。
     - 线性探测：冲突发生时，按序查看表中下一个空闲单元。
     - 平方探测：冲突发生时，按序查看相对原址$1,-1,2^2,-2^2,...$的下一个空闲单元。
     - 双散列：第一个散列函数冲突，则使用第二个散列函数。
     - 随机数
   - 拉链：同义词存于同一个链表中。

4. 散列表的查找效率取决于：散列函数、处理冲突办法、装填因子

   - 装填因子=记录数/表长。



## 5. 排序



### 5.1 概念

1. 排序：重新排列表中元素，使之按关键字有序。

2. 排序算法的稳定性：对于关键字相同的两个元素，使用算法排序后是否顺序变化。

3. 内部排序：排序期间元素全部存放在内存。

   外部排序：排序期间元素无法同时全部存放在内存。



### 5.2 排序算法

#### 插入排序

1. 直接插入排序：每次将一个元素按其关键字插入已经排序好的子序列。
   - 空间复杂度$O(1)$，时间复杂度$O(n^2)$。如果原顺序较好，时间复杂度可为$O(n)$。
   - 稳定排序，适用于顺序表和链表。
2. 二分插入排序：二分查找插入位置的插入排序。
   - 空间复杂度$O(1)$，时间复杂度$O(n^2)$。
   - 稳定排序，适用于顺序表。
3. 希尔排序：取一个小于$n$的值$d$，将元素分为可有交集的$d$组，所有距离为$d$的倍数的元素分在一组，在各组内进行直接插入排序，然后取小于$d$的值$d'$，重复，直到最后进行一次全表的直接插入排序。
   - 不稳定排序，适用于顺序表。



#### 交换排序

1. 冒泡排序：从后往前两两比较相邻元素的值，逆序则交换。重复直到一次遍历中不发生交换。
   - 空间复杂度$O(1)$，时间复杂度$O(n^2)$。
   - 稳定排序，适用于顺序表和链表。
2. 快速排序：在表中任取一个元素，一次遍历将表分为小于该元素和大于该元素的两个部分，再对这两个部分分别进行快速排序。
   - 空间复杂度$O(1)$，时间复杂度$O(n^2)$。如果划分平均，时间复杂度可为$O(n\log_2n)$
   - 不稳定排序，适用于顺序表。
   - 快速排序是内部排序算法中平均性能最优的排序算法。



#### 选择排序

1. 简单选择排序：每次选取待排序元素中最小的元素作为有序子序列的最后一个元素。

   实现：将后$n-i+1$个元素中的最小者与第$i$个元素交换。

   - 空间复杂度$O(1)$，时间复杂度$O(n^2)$。
   - 不稳定排序，适用于顺序表和链表。

2. 堆排序：建堆，然后逐个输出元素。

   - 空间复杂度$O(1)$，时间复杂度$O(n\log_2n)$。
   - 不稳定排序，适用于顺序表。

   堆是一种二叉树，一般用完全二叉树来实现，顺序存储。

   - 任意结点值大于其子结点值的堆是最大堆。
   - 任意结点值小于其子结点值的堆是最小堆。

   插入：先把新结点放在最后，然后逐层比较其与父结点的值，如果违反定义就交换，直到无法交换。

   删除：一般使用自顶向下堆化。

   - 自顶向下堆化：删除根结点，用最后一个结点取代它，然后逐层比较其与子结点的值使其下沉。
   - 自底向上堆化：删除根节点，用更大的子结点取代它，重复（会产生空结点位置）



#### 归并排序

归并排序：将表分为多个表进行排序，然后合并。

二路归并排序：将表分为两个子表，对每个子表递归使用二路归并排序，然后合并。

- 合并：每次选择两个子表中的较小者写入辅助数组。
- 空间复杂度$O(n)$，时间复杂度$O(n\log_2n)$。
- 稳定排序，适用于顺序表和链表。



#### 基数排序

基数排序：基于关键字各位的大小进行排序。

- 从最低位开始的基数排序：从最低位开始，每一位排序一次。
- 空间复杂度$O(r)$，$r$为进制数，时间复杂度$O(d(n+r))$，$d$为最大位数。
- 稳定排序，适用于顺序表和链表。

基数排序的本质是将多关键字的排序算法用于单关键字。



#### 计数排序

对每个待排序元素，统计小于其的元素个数。

- 计数数组长度为$k$，空间复杂度$O(n+k)$。
  - 当$k=O(n)$，时间复杂度$O(n)$。

- 稳定排序，适用于顺序表。



### 5.3 内部和外部排序

1. 内部排序算法考虑因素：

   - 元素个数。
   - 元素初始状态。
   - 关键字的结构与分布。
   - 稳定性的要求。
   - 存储空间及辅助空间大小。

   排序算法使用总结：

   - 元素数量：
     - 较小：直接插入排序、简单选择排序。
     - 较大：选择时间复杂度为$O(n\log_2n)$的算法。关键字可分解且位数少，用基数排序。
   - 稳定性要求：
     - 不稳定：希尔排序、快速排序、简单选择排序、堆排序
   - 初始状态：基本有序，则用直接插入、冒泡排序
   - 信息量大：用链表。

2. 外部排序：大文件的排序。常用归并排序算法。

   - 败者树
   - 置换-选择归并
   - 最佳归并树
