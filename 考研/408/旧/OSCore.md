# OSCore

## OS基础

1. 操作系统的定义
2. 操作系统的特征：并发、共享、虚拟、异步
3. 操作系统的功能：资源管理、用户接口
4. 操作系统的结构：分层、模块、内核结构（微内核和宏内核）
5. 操作系统的引导



## 处理器管理

1. 处理器的构成：算术逻辑单元、控制单元、各种寄存器

2. 机器指令、处理器模式和特权指令

3. 进程、进程控制块和进程映像

   - 进程的状态和进程控制

   - 进程的通信

4. 线程、多线程环境、线程的三种实现

5. 处理器调度、调度层次、调度时机、作业调度算法（FCFS、SJF、高响应比、时间片轮转）



## 内存管理

1. 编译、链接（静态、装入时动态、运行时动态）、装入（绝对、可重定位、动态运行时）
2. 逻辑与物理地址、内存保护
3. 内存分配：单连续分区、分页、分段、段页
4. 内存扩充（虚拟内存）
   - 页面分配策略：固定分配，局部置换；可变分配，局部置换；可变分配，全局置换
   - 页面置换算法：OPT、FIFO、LRU、LFU、时钟



## 文件管理

1. 文件控制块、文件目录项、文件索引
2. 文件操作：创建、删除、打开、关闭、读写
3. 文件保护：访问类型和访问控制
4. 文件结构：
   - 逻辑结构：流式文件、记录式文件
   - 物理结构：顺序文件、连接文件（隐式和显式）、索引文件、直接文件
5. 文件目录：目录结构、目录操作、目录实现、文件共享（软硬链接）
6. 文件系统：实现结构
   - 外存空间管理：存储区分配（连续与非连续）、空闲块管理（空闲表、链表、位示图、成组链接）
   - 虚拟文件系统：超级块、索引结点、目录项、文件对象



## 设备管理

1. 设备分类：信息传输、共享方式、信息单位
2. 输入/输出控制：
   - 设备控制器
   - 控制方式（轮询、中断、DMA、通道）
   - 输入/输出软件层次
   - 输入/输出缓冲和SPooling技术
3. 设备分配
4. 磁盘结构、读写方式、移臂调度、旋转调度



## 并发控制

1. 并发进程的竞争和协作
2. 临界区互斥准则、Peterson算法、测试并建立TS、Swap、互斥锁、信号量和PV操作。
3. 死锁：四个必要条件、预防、避免、检测和解除。
