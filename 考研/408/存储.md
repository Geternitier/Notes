# 存储

## 1. 硬件

### 1.1 概述

芯片通常由内核、高速缓存、内存控制器、通信基带、片上总线、外部总线接口等构成。

1. **高速缓存 Cache**，又分L1、L2、L3等级别，是紧贴CPU内核的存储器。
2. **内存**：常规读写时逐级Cache未命中，CPU使用内存控制器从内存读取数据到Cache。
3. **外存**：从外设（硬盘）获取数据，写入内存。

**高速缓存 Cache**是紧贴CPU内核的存储器，用于加速CPU访问内存。

1. CPU的速度比内存快，且两者差距不断扩大，这称为**内存墙**。
2. 处理器频繁访问主存中相同位置或者相邻存储位置的现象，这称为**局部性原理**。

   - 时间局部性：在相对较短的时间周期内，重复访问特定的信息
   - 空间局部性：在相对较短的时间内，访问相邻存储位置的数据
   - 顺序局部性：数据被线性排列访问时，出现的一种空间局部性的特殊情况

也存在部分场景，数据不经Cache而是直接在内核和内存间传递，例如：

1. 网卡、显卡等设备寄存器保存实时信息不可缓存；
2. 读写大批量一次性数据时，可以软件指定绕过缓存。



存储器由若干可被唯一标识并存储一个数值的**存储单元**构成。

1. 存储单元的唯一标识符称为**地址**，地址的总和称为**地址空间**；
2. **存取时间**是一次读/写操作所需时间。
3. **存储周期**是完成两次连续独立读/写操作所需的最小时间间隔。
4. **存储带宽**是存储器每秒能传递的最大数据量。



### 1.2 DRAM

Dynamic Random Access Memory，简称**DRAM**，是内存的物理结构。

DRAM的存储单元是一个**晶体管 Transistor**和一个**电容 Capacitor**，简称**1T1C**。



#### NMOS

DRAM的晶体管通常是NMOS，N-Channel MOS，N-Channel指栅极通电时打开电子通道。

     		         栅极 Gate
    		 	     ┌───┴──┐
    漏极 Drain ─┤ NMOS ├─ 源极 Source
    		       └──────┘
低电平NMOS关闭，高电平NMOS导通。



#### 1T1C

```
											字线 Word Line
														|
											     栅极																 数据总线
		 	                   ┌──┴───┐																 |
电容 Capacitor ———— 源极 ─┤ NMOS ├─ 漏极 —— 位线 Bit Line —————  选择电路
		   |                 └──────┘							|
	地线 Ground = 0V									感知放大器 Sense Amplifier
```

**写入1**：

1. 字线高电位，NMOS导通；
2. 位线高电位，电容充电，Capacitor = 1。

**写入0**：

1. 字线高电位，NMOS导通；
2. 位线低电位，电容放电，Capacitor = 0。

**读取**：

1. 位线预充电至中间电位；
2. 字线高电位，NMOS导通；
   1. Capacitor = 1，电容放电，位线电位升高；
   2. Capacitor = 0，电容充电，位线电位下降。
3. 感知放大器根据位线电位变化，更新位线电位为1或0；
4. 位线电位写回到电容，恢复电容值。

机制蕴含性质：

1. 位线不能过长，否则读取时检测电压变化困难。一般行数为512或1024行。
2. 由于电容会流失电荷，需要周期进行**刷新**（即做一次读取）。



#### 阵列

1T1C通常以矩阵形式连接，一个1T1C矩阵称为一个**阵列 Subarray**。

1. 假设存储矩阵为$\mathbf C_{m\times n}$，有$m$条字线，$n$条位线；
2. 激活$i$行字线，$j$列位线，即可访问$c_{ij}$；
3. 由于位线相互独立，激活$i$行字线时可以同时读出一整行的数据。
4. 实际上，每次访问会基于字线读取一整行到行缓冲，再由列地址选择输出数据。

```
       位线0      位线1      位线2    ...
         |         |         |
字线0 ---C0--------C1--------C2------...
         |         |         |
字线1 ---C3--------C4--------C5------...
         |         |         |
字线2 ---C6--------C7--------C8------...
         |         |         |
...     ...       ...       ...
         |				 |				 |
        SA0       SA1       SA2     ... (Sense Amplifier)
      ┌──┴─────────┴─────────┴───┐ 
      |     行缓冲 Row Buffer     |      (SA提供Row Buffer功能)
      └──────────────────────────┘	
```

一个列地址往往对应多条位线，这称为**列访问粒度**：

1. 例如，一共8192条位线，列访问粒度为8，则列地址一共1024。
2. 输入列地址k，行缓冲将8k~8k+7的8位数据一同输出。
3. $1\mathrm M\times 8\mathrm{bit}$指有$2^{20}$个地址，每个地址输出8位。

阵列设计：

1. 为减少地址线，行列地址用相同地址线两次传递，这称为**地址复用**。
2. 单次刷新次数即行数。为减少刷新，通常将矩阵设计为行数小于等于列数。
3. 综合考虑，矩阵一般设计为行数略小于或等于列数的方阵。

**突发传输 Burst**：一次激活，连续多次读取。

1. CPU要读取连续多个列地址的数据；
2. 内存控制器指定读取的首地址和突发长度；
3. 激活一次字线后，按首地址和突发长度从行缓冲连续读取数据。

突发传输是单体多字（单体存储，一次传输多个数据）的一种实现。



#### 存储体

Subarray一次只能访问一行，如果按顺序编址，相邻的行需要多次启动一个Subarray完成访存，为了提高并行度，可以把相邻行存储在不同阵列中，这种编址方式称为**交叉编址**。

1. 使用多个阵列存储数据，如果顺序编址，则地址「阵列号｜行号｜列号｜列内偏移」；
2. 交叉编址采用「行号｜阵列号｜列号｜列内偏移」。

```
Bank
┌─┴───────────┬──────────┐ 
Subarray0   Subarray1   ...
```

使用多个Subarray构成**体 Bank**，Bank内各阵列顺序编址，Bank间交叉编址。

1. 地址结构「Subarray号｜行号｜Bank号｜列号｜列内偏移」
2. 一般「Subarray号｜行号」未必进行顺序编址，具体实现由内存芯片设计确定；
3. 内存控制器只感知「行号｜Bank号｜列号｜列内偏移」，行号=「Subarray号｜行号」。
4. 现代内存往往采取「Bank号1｜行号｜Bank号2｜列号｜列内偏移」的结构，两部分Bank号函数映射（例如异或）到实际Bank号，来进一步提高并行度。

Bank访存的**轮流启动**机制，称为**Bank interleaving**：

1. 不同Bank可以独立启动，存取周期也独立。
2. 假设存取周期是T，总线周期为r；
3. 启动流水线：每隔r启动一个Bank，过了时间T，可以每隔r返回一次数据；
   1. 当有$m=\frac Tr$个Bank，就可以隐藏存取周期；
   2. 但更多访存机制，例如突发传输使存取加速，使得Bank数量未必会如此设计。
4. 同一个存取周期两次访问同一个Bank会引发冲突，延迟流水线进行。

为了实现更高的带宽，DDR4引入了**Bank Group**：

1. 每个Bank Group包含多个Bank，不同Bank Group可以轮流启动；
2. 物理地址「行号｜Bank Group号｜Bank号｜列号｜列内偏移」。

多个Bank Group就构成一个**DRAM颗粒**。



#### 芯片组

一次访问一个DRAM颗粒只能返回列访问粒度的位数，采用**位扩展**可以一次访问更多位数。

1. 例如，DRAM颗粒的列访问粒度为8位，8个DRAM颗粒同时读取可以扩展为64位；
1. 使用多个DRAM颗粒组合，扩展数据宽度的结构称为**芯片组 Rank**。
1. 物理地址「行号｜Rank号｜Bank Group号｜Bank号｜列号｜列内偏移」。
1. 指定物理地址时，对应Rank内多个DRAM颗粒相同地址的Bank同时启动，共同读取数据。

同时启动读取的数据在物理地址上是连续的，因此编程的**内存对齐**有利于减少读取次数。



#### 通道

**通道 Channel**直接对接内存控制器，具有独立的地址、数据、控制线。

```
通道 Channel
  ┌─┴──────┬─────────┐ 
Rank0    Rank1      ...
  ┌────────┴┬─────────┐
Chip0     Chip1      ...
```

1. 一个通道连接多个Rank。
2. **地址线**通过行列地址复用，两次传递地址指定存储单元；
3. **数据线**决定一次读写的总位数，称为**存储字长**。
4. 每个Rank对应一根**片选 Chip Select CS**线，CS_i=1指定Rank_i激活；
5. 同一时间只能有一个Rank使用通道，但是Rank可以独自先准备数据。

这种一对一的选片方式称为**线选法**，下层都采用n对$2^n$的**译码片选**。

控制线结构：

1. CS，片选线
2. CK，时钟线：控制时钟同步。
3. CKE，Clock Enable：控制进入省电模式和唤醒。
4. ODT，On Die Termination：控制终端电阻，减少高速信号反射，用于改善电气性能。
5. RAS 行地址、CAS 列地址、WE 写使能：组合完成指令
   1. ACT 激活行：RAS有效，地址线传递Bank和Row；
   2. READ/WRITE 读/写：CAS有效，地址线传递Column，如果WRITE则WE有效；
   3. PRECHARGE 预充电：CAS有效，地址线传递Bank；
   4. REFRESH 刷新：WE有效，CS指定的Rank进行刷新。

存储访问过程：

1. CS选择Rank；
2. ACT；
3. READ/WRITE命令。



#### 内存控制器

内存控制器连接多个通道。

1. 不同通道有独立的地址、数据和控制线，因此访存独立。
2. 内存控制通过地址、数据和控制线直接控制访存流水线。
3. 物理地址「通道号｜行号｜Rank号｜Bank Group号｜Bank号｜列号｜列内偏移」。
   - 实际上，这个顺序并非固定，而是由内存控制器实际优化决定。

内存控制器控制**DRAM刷新**：

1. 集中刷新：停止读写，刷新每一行；刷新时无法操作内存
2. 分散刷新：每个存储周期内，读写完成时刷新；增加存储周期时间
3. 异步刷新：现代常用
   1. 每一行各自以一定间隔刷新；
   2. 由内存控制器按照间隔把刷新任务分散完成。



#### Load/Store

Load：

1. 由Load单元生成访存请求；
2. 查询Cache；若Cache未名字，将包含物理地址的读请求发送给内存控制器；
3. 内存控制器根据地址通过Channel访问DRAM；
4. DRAM返回数据经Channel和内存控制器传输到Cache。

Store：

1. Store单元生成包含物理地址和数据的写请求；
2. 写请求进入Cache，根据缓存一致性策略处理；
3. 内存控制器接收到写请求后，调度Channel写数据。



#### DRAM历史

下述仅为典型取值。

1. 异步DRAM
2. **同步 Synchronized** DRAM：数据发送和时钟信号同步。
3. **双速率 Double Data Rate** SDRAM：在时钟的上升和下降沿发送数据。
   1. DDR4引入了Bank Group；
   2. DDR5将通道拆分为2个子通道。

| 层级              | SDRAM | DDR   | DDR2  | DDR3  | DDR4  | DDR5  |
| ----------------- | ----- | ----- | ----- | ----- | ----- | ----- |
| Rank              | 8x8位 | 8x8位 | 8x8位 | 8x8位 | 8x8位 | 8x8位 |
| 每Chip Bank数     | 4     | 4     | 4或8  | 8     | 4x4   | 8x4   |
| 每Bank Subarray数 | 2～16 | 16    | 64    | 16    | 16    | 32    |



### 1.3 SRAM

Static Random Access Memory，简称**SRAM**，是Cache的物理结构。

SRAM的存储单元是6个**晶体管 Transistor**，简称**6T**。



#### PMOS

6T由PMOS和NMOS构成，PMOS即P-Channel MOS，是利用空穴作为载流子的MOS。

```
 		         栅极 Gate
		 	     ┌───┴──┐
漏极 Drain ─┤ PMOS ├─ 源极 Source
		       └──────┘
```

低电平PMOS导通，高电平PMOS关闭。

一个PMOS和一个NMOS构成一个**反相器 CMOS**。

```
 		  			  固定直流电压 VDD
 		  			        |
 		  			      source 源极
		            ┌───┴──┐
	     ┌─ gate ─┤ PMOS ├─ drain ─┐          gate: 栅极
input ─┤        ├─    ─┤         ├─ output
		   └─ gate ─┤ NMOS ├─ drain ─┘          drain: 漏极
		            └───┬──┘
		             source 源极
		                |
		           地线 Ground
```

输入为1，NMOS导通，output为0；输入为0，PMOS导通，output为1。



#### 6T

将两个CMOS交叉连接：

1. CMOS1的输出记为Q，连接到CMOS2的栅极；
2. CMOS2的输出记为QB，连接到CMOS1的栅极；
3. 当Q=1，QB=0；当Q=0，QB=1。构成两种稳定状态，代表二进制的0和1。
4. 这称为**交叉耦合反相器**。

```
 		  			         ┌──── 固定直流电压 VDD ───┐
 		  			     source 源极             source 源极
		             ┌───┴──┐                ┌───┴──┐
	               | PMOS ├─ gate    gate ─┤ NMOS |
                 └───┬──┘   |        |   └───┬──┘
                   drain    |┌───────┘    drain 漏极
   					 		 	 	 |			└────────┐			 |
									   Q  ─────┤			 ├────── QB
										 |			┌────────┘			 |
 		  			       drain    |└───────┐    drain 漏极
		             ┌───┴──┐   |        |   ┌───┴──┐
		             | NMOS ├─ gate    gate ─┤ PMOS |
		             └───┬──┘							   └───┬──┘
		             source 源极               source 源极
		                 └────── 地线 Ground ─────┘
```

交叉耦合反相器搭配两个NMOS即构成6T。

```
			          ┌──────── Word Line ───────┐
		           gate                      gate
            ┌───┴──┐  ┌─────────────┐  ┌───┴──┐
            | NMOS ├─ Q Cross CMOS QB ─┤ NMOS |
            └───┬──┘	└─────────────┘  └───┬──┘
             Bit Line                  Bit Line B
                └───── Sense Amplifier ────┘
```

读取时：

1. 字线高电位，两个NMOS导通；
2. Q、QB的点位传递给位线BL和位线BLB；
3. 感知放大器SA检查BL和BLB的电位高低，输出结果；
4. 字线关闭，交叉耦合反相器自动恢复。

写入时：

1. 设置BL、BLB电位；
2. 字线高电位，两个NMOS导通；
3. BL、BLB的电位传递给Q和QB；
4. 字线关闭。

6T和1T1C对比：

1. 6T单位面积更大，数据密度低，成本高；
2. 交叉耦合反相器稳定，不需刷新；
3. 交叉耦合反相器对位线的电位影响比电容更大，感知放大也更快。



#### 阵列

6T通常以矩阵形式连接，一个6T矩阵称为一个**阵列 Subarray**。

1. 假设存储矩阵为$\mathbf C_{m\times n}$，有$m$条字线，$n$对位线BL/BLB；
2. 激活$i$行字线，$i$行的数据更新到每个位线对上；
3. 列选择器根据列地址和列访问粒度选定一组位线对；
4. 这一组位线对的数据经感知放大器放大，传输到数据缓冲，待传输给CPU。

```
       BL/BLB0  BL/BLB1   BL/BLB2   ...
         |         |         |
字线0 ---C0--------C1--------C2------...
         |         |         |
字线1 ---C3--------C4--------C5------...
         |         |         |
字线2 ---C6--------C7--------C8------...
         |         |         |
...     ...       ...       ...
         |				 |				 |
         └─────────┴┬────────┘
             列选择器 Column MUX
          				  |
             Sense Amplifier
             				|
             	 Data Buffer
```

1. 位线对先经列选择，再感知放大是一种性能平衡方案：
   1. 每列一个放大器会使电路空间膨胀；
   2. 每列一个放大器会增加位线负载，影响位线电位变化的速度；
2. 但也有小型高速SRAM会选择给每列一个放大器。

类似DRAM，多个6T阵列构成一个**存储体 Bank**。

1. 同一个Bank内同时只激活一个Subarray；
2. 不同Bank间进行低位交叉编址，可能使用行内地址进行交叉。

多个Bank构成一个**宏单元Macro**，Macro向**Cache控制器**提供读写的原子操作。



### 1.4 Cache

#### 访存

CPU访问内存不会直接调用内存控制器，而是将指令发给Cache控制器。

1. 数据在Cache中，由Cache控制器读取或写入数据；
2. 数据不在Cache中，由Cache控制器请求内存控制器读入数据到Cache，再进行处理。

Cache和内存的**一致性**：

1. **直写 Write Straight**：所有写操作同时对Cache和主存进行。
   - 优点：确保主存中数据总是和Cache中一致。
   - 缺点：产生大量主存访问，减慢写的操作。
2. **回写 Write Back**：写操作先更新Cache，块被替换时，若修改则写回主存。
   - 维护一位表示块是否被修改。
   
   - 优点：减少了访问主存的次数。
   - 缺点：部分主存数据不是最新的。

时间计算：命中率$p$，Cache访问时间$T_C$，主存访问时间$T_M$，平均访问时间$T_A$

1. $T_A=T_C+(1-p)T_M$
2. $p$越大，$T_C$越小，效果越好。
3. $T_A\lt T_M$的条件是$p\gt \frac{T_C}{T_M}$
4. Cache增大使得$p$增大，但$T_C$也增加



#### 映射

1. Cache和内存交换数据的最小单位是一个**行**，往往比页更小；
2. 地址「页号｜页内偏移」，又可分为「前缀｜行内偏移」；
3. 直接映射：前缀%行数=行号。
   1. 地址「标记｜行号｜行内偏移」
   2. 访问快，但可能引发抖动。
4. 全关联映射：内存块可以装入Cache的任意块号。
   1. 地址「标记｜行内偏移」
   2. 需遍历，访问慢。
5. **组关联映射**：将Cache行分组，前缀%组数=组号，组内任意装入。
   1. 地址「标记｜组号｜行内偏移」
   2. 称组中的一行为一路，若组中有k行，就称k路组关联映射。



#### 替换

随机 RAND，先进先出 FIFO，最近最少 LRU，最不常用 LFU

**LRU**，最近使用的块更可能使用，替换最长时间未被访问的块

1. 2路组关联映射
   1. 每行包含一个USE位；
   2. 在同一组中的行被访问时，将其USE值设为1，将另一行的USE位设为0；
   3. 新数据块读入时，替换USE值为0的数据块。
2. 4路组关联映射
   1. 每行包含两个USE位；
   2. 在同一组中的行被访问时，将其USE值清0，其余非空行的USE值+1；
   3. 新数据块读入时，替换USE值最大的数据块。

**LFU**，访问越频繁越有可能使用，替换访问次数最少的块；为每一行设置计数器。



#### Cache控制器

一个Cache在物理上分为3个部分，每个部分由各自的Macro构成：

1. 标记 Tag：存放Tag
2. 数据 Data：存放数据
3. 元数据 Meta：存放脏位等控制信息

```
Cache Controller
  ┌───────┴┬────────┐ 
 Tag      Data     Meta
  |        |        |
Macros   Macros   Macros(Simplified)
```

Cache控制器将物理地址翻译成「标记｜组号｜行内偏移」，并到对应Macro检查和读取数据。



### 1.5 ROM

**只读存储器 ROM**：非易失，不需要供电维持；可读但不能写。

1. 可编程ROM，PROM：用熔丝存储数据，熔断后无法恢复，只能写入一次。
2. 可擦除PROM，EPROM：紫外光擦除，电写入，更贵但能多次改写。
3. 电EPROM，EEPROM：随时写入。更贵，密度低于EPROM。
4. 快闪存储器，Flash Memory：电可块级擦除，密度与EPROM相同，价格在EPROM和EEPROM间。



### 1.3 外存

用于存储不经常使用的、数据量较大的信息；非易失

#### 磁盘

由涂有可磁化材料的非磁性材料构成的圆形盘片，分为**软盘**和**硬盘**。

硬盘结构：

1. **磁盘驱动器**驱动磁盘转动并在盘面上通过磁头进行读写；
2. **磁盘控制器**是磁盘驱动器与主机的接口；
3. **存储区**包含多个盘片：
   1. 每个盘片有两个盘面，每个盘面有一个读写磁头。
   2. 盘面上有多个同心圆结构的磁道，相邻磁道间存在间隙。
   3. 磁道分为多个扇区，相邻扇区间存在间隙，相邻多个扇区组合成簇，按簇读写。
   4. 不同盘片相同位置的磁道构成柱面。
4. 磁盘地址：「柱面（磁道）号｜盘面号｜扇区号」。
   1. 沿磁盘半径方向单位长度上的磁道数称为**道密度**；
   2. 磁道单位长度上的位数称为**位密度**；
   3. 盘面单位面积上的位数称为**面密度**，是位密度和道密度的乘积。

磁盘容量：

1. 非格式化容量：可用磁化单元总数，记录面数$\times$柱面数$\times$每条磁道的磁化单元数；
2. 格式化容量：按某种特定格式能容纳的量，记录面数$\times$柱面数$\times$每道扇区数$\times$每扇区容量。

**存取时间**=寻道时间+旋转延迟+传输时间：

1. **寻道时间**是磁头定位到磁道的时间；**寻道算法**有
   1. 先来先服务 FCFS
   2. 最短寻道时间优先 SSTF
   3. 扫描/电梯 SCAN：磁头按照一个方向移动到边缘，然后返回
   4. 循环扫描 CSCAN：磁头只在往一个方向移动时进行读写，返回时不处理
   5. 电梯 LOOK：SCAN时，如果方向上没有请求就返回
   6. 循环电梯 CLOOK：CSCAN时，如果方向上没有请求就返回
2. **旋转延迟**是磁头转到扇区起始处的时间，**平均旋转延迟**是旋转半周的时间；
   1. 通过优化访存顺序和多磁头读写，可以改善旋转延迟；
   2. 通过优化数据分布（成簇读写、交替存储等）也可改善。
3. **传输时间**：数据传输速率$rN$，其中磁盘转速$r$转每秒，每条磁道容量$N$字节。
   - 需要传输$b$字节，则传输时间$\frac{b}{rN}$。



#### 固态硬盘

**U盘**采用了快闪存储器，非易失，比软盘和光盘体积小、容量大、便携、寿命长。

**固态硬盘 SSD**与U盘本质相同，容量更大，存储性能更好。

1. 与硬磁盘存储器相比：抗振性好、无噪声、能耗低、发热少
2. **磨损均衡**：闪存的擦写次数有限，如果集中在几个闪存块进行读写，会导致其磨损较快
   - 动态磨损均衡：写入时自动选择较新的闪存块
   - 静态磨损均衡：SSD自动检测并进行数据分配，使得平时的读写在较新的闪存块进行



#### 冗余磁盘阵列

简称RAID。

1. RAID0：无冗余、无校验磁盘阵列，通过多个磁盘进行存储提高读写速度
2. RAID1：镜像磁盘阵列，通过磁盘镜像提高安全性
3. RAID2：海明码磁盘阵列
4. RAID3：位交叉奇偶校验磁盘阵列
5. RAID4：块交叉奇偶校验磁盘阵列
6. RAID5：无独立校验的奇偶校验磁盘阵列



## 2. 软件

### 2.1 概述

#### 虚拟存储空间

程序访存具有**局部性原理**：

1. 时间局部性：相同存储单元局部时间内集中访问；
2. 空间局部性：局部空间内存储单元集中访问。

程序访问的存储空间往往远大于内存空间，根据局部性原理，采用**虚拟存储**方式。

1. 内存地址空间称为**物理地址空间**；
2. 进程使用**虚拟地址空间**，通常远大于物理地址空间，例如64位linux有128TB虚拟地址空间；
3. 进程的文件、堆栈、动态链接库都映射到虚拟地址空间，代码只访问虚拟地址空间。
4. 访存时，CPU进行地址转换，把虚拟地址空间映射到物理地址空间，按需将虚拟地址对应的数据调入，或为之分配内存。

为防止多道程序相互干扰，限制程序访问的地址空间，称为**内存保护**，通常两种方式：

1. 上、下限寄存器：存储进程的上下限物理地址。
2. 基址、限长寄存器：存储进程的起始物理地址和限制长度。



#### 分段程序设计

**分段程序设计**将一个程序分为代码段、数据段、堆栈段等多个段。

1. 代码、数据的地址用「所在段｜段内偏移」表示。
2. 进程中设有段表，段表项称为**段描述符**「始址｜限长｜控制信息」。

分段程序的虚拟地址空间：

1. 0地址开始的低地址区域用于空指针和解引用，不可访问；
2. 编译时固定：代码段、数据段、堆依次从某个地址开始分布，栈从地址空间顶部向下生长；
3. 执行时**低址空间布局随机化 ASLR**：在一定范围内随机分配地址，以防止遭受攻击。



#### 分页存储分配

**分区存储分配**将物理地址空间按分区分配给程序。

物理地址空间划分为多个连续分区内，将整个程序段载入一个分区，称为**连续分区分配**：

1. **单分区**：物理地址空间划分为系统区和用户区。
2. **固定分区**：物理地址空间划分为多个大小固定的分区。
   1. 用**分配表**管理分区分配。
   2. 产生**内部碎片**，即分区中空闲的部分。
3. **可变分区**：根据进程所需、内存空闲进行分配。
   1. 用**已分配分区链表**和**空闲分区链表**管理分区分配。
   2. 产生**外部碎片**，即分区间空闲的部分。



将物理和虚拟地址按固定单位划分，该单位称为**页**，程序按页载入内存，称为**分页存储分配**。

1. 地址按页划分为「页号｜页内偏移」
   1. 例如，Mac的页为$16\mathrm{KB}=2^{14}\mathrm{B}$；
   2. 物理地址空间$16\mathrm{GB}=2^{34}\mathrm{B}$，「20位物理页号｜14位页内偏移」；
   3. 虚拟地址空间$128\mathrm{TB}=2^{48}\mathrm{B}$，「34位虚拟页号｜14位页内偏移」。
2. 进程设置**页表**，页表项「物理页号｜控制信息」
   1. 页表占一个页，64位系统的页表项一般为64位。例如，16KB页含$2\mathrm K=2^{11}$个页表项；
   2. 34位虚拟页号可划分为1+11+11+11四级页表，高级页表也称**页目录**；
   3. 页表项指向页表时，页表地址为「物理页号｜页内偏移0」。
3. 访问某个虚拟地址时，根据虚拟页号逐级查页表：
   1. 如果存在，替换虚拟页号为物理页号，得到物理地址；
   2. 如果不存在，触发**缺页异常**，内核分配物理页，更新页表。



**段页式存储管理**：

1. 程序分段，代码、数据的地址用「所在段｜段内偏移」表示；
2. 进程设段表，段表项「段始址｜段限长｜控制信息」；
3. 按分页存储分配方式访问虚拟地址（段始址+段内偏移）。



### 2.2 分配

#### 分区分配

可变分区**顺序分配算法**：

1. 最先适应：空闲链表按地址升序，顺序查找第一个满足分区；综合性能最佳
2. 邻近适应：从上次查找结束的地方开始查找；导致高地址的大分区减少
3. 最优适应：空闲链表按大小升序，顺序查找第一个满足分区；外部碎片最多
4. 最坏适应：空闲链表按大小降序，顺序查找第一个满足分区；导致无大分区可用

可变分区**索引分配算法**：设置索引表管理过长的空闲分区链表，每个分区大小为一个索引

1. 快速适应：适配的最小分区索引的第一个分区。
2. 哈希：构建关键字为分区大小的哈希表。
3. 伙伴系统：
   1. 当需要分配大小为$n,2^{i-1}\lt n\lt 2^i$的分区，查找大小为$2^i$的分区链，若有则分配；
   2. 若无，查找$2^{i+1}$的分区链：
      1. 若有，将其分为两个$2^i$的分区，这两个分区称为伙伴，其中一个进行分配，另一个加入$2^i$的分区链；
      2. 若无，类推。



#### 分页置换

分配给进程的物理页是有限的，当没有空闲页时，需要选择物理页作为新的虚拟页。

1. **固定分配 局部置换**：分配固定物理页，在其中置换。
2. **可变分配 局部置换**：分配一些物理页，在其中置换，缺页率高就额外分配，反之收回。
3. **可变分配 全局置换**：分配一些物理页，缺页时，在内存所有物理页中选择置换。

**置换算法**：

1. **最优置换 OPT**：先淘汰不再访问的页，后淘汰距现在最长时间后访问的页。
2. **先进先出 FIFO**：淘汰最先调入主存的页。
   - 分配物理页增多，缺页次数可能反而增加，称为Belady异常。
3. **最近最少用 LRU**：淘汰最久未被访问的页。
   - 严格实现的代价大：维持特殊队列。

4. **最不常用 LFU**：淘汰最近一段时间内访问次数较少的页。

5. **时钟**：用循环队列构造页面队列，队列指针指向可能要淘汰的页
   1. 页面调入主存时，引用标志位被置为1
   2. 访问主存页面时，引用标志位被置为1
   3. 淘汰页面时，从指针当前指向的页面开始扫描循环队列
      - 将所遇到的引用标志位是1的页面的引用标志位清0，跳过
      - 将所遇到的引用标志位是0的页面淘汰，指针推进

衡量置换算法的性能：

1. **缺页率**：总访存n次，缺页m次，缺页率为$\frac mn$。
2. 是否发生**抖动**：同一页面短时间内被反复调入调出。



### 2.3 地址转换

#### 链接

**编译**，生成多个目标文件：

1. 目标文件包含段、符号表、重定位表、其他信息；
2. **符号表**记录「符号名｜类型｜段｜段内偏移」
   1. 符号名：编译器生成的函数名、变量名
   2. 类型：本地、外部定义、未定义
   3. 段：代码段、数据段、待提供（外部和未定义）
   4. 段内偏移：符号在段中的相对地址。
3. **重定位表**记录「逻辑地址｜重定位方式｜符号」
   1. 逻辑地址：符号在段中的地址。
   2. 重定位方式：
      1. 本地地址：加上页基址
      2. 函数调用：call（x86）、bl（arm）
      3. 外部符号：对应页基址+偏移

**链接**，生成可执行文件：

1. 汇总符号表，解析外部符号地址；
   1. 此时所有目标文件包含的符号位置确定，这些符号称为**静态符号**；
   2. 如`_printf`的动态库符号编译时地址不确定，称为**动态符号**。
2. 将所有目标文件的段合并，分配虚拟地址；
3. 根据重定位表，将代码中静态符号全部更新为地址；
4. 根据重定位表，更新动态符号的代码，补充动态链接相关信息；
5. 最终文件包含「首部｜各个段｜附加信息」

根据总符号表确定静态符号地址并更新代码的过程称为**静态链接**，完成静态链接后，代码中的静态符号都替换为虚拟地址。

确定动态符号虚拟地址的过程称为**动态链接**，通常在程序执行前或执行中完成，因此一般会在进程中维护动态符号表，保存「符号｜虚拟地址」映射，使用动态链接器进行未定义符号的解析。

1. 装入时动态链接：装入时，先动态链接，再执行程序。
2. 运行时动态链接：先执行程序，使用到动态符号时再进行动态链接。



#### 执行

装入时地址转换：

1. 绝对装入：链接后代码中是物理地址，将程序装入固定的物理地址。
2. 可重定位装入：链接后代码中是虚拟地址，装入时修改为物理地址。

3. 动态运行时装入：链接后代码中是虚拟地址，装入不修改地址，执行时自动转换。

由于查页表+查地址需两次访存，通常在CPU增设**快表 TLB**存放部分表项以减少一次访存。

1. 快表按CPU设置，不对进程单独开设。
2. 多级页表系统中往往也有多级快表。

**带有快表的段页式地址转换**：已知所在段和段内偏移

1. 查段表得段基址和段限长，判断段内偏移是否越界；
2. 虚拟地址=段基址+段内偏移；
3. 用虚拟页号查快表，
   1. 若存在，替换物理页号，形成物理地址；
   2. 若不存在，查页表。
      1. 若存在，替换物理页号，形成物理地址。
      2. 若不存在，缺页异常，检查地址合法性、调入页并更新页表，再次执行指令。
      3. 更新快表，如果快表填满，按一定策略置换一个旧项。



带有Cache和快表的段页式地址转换：已知所在段和段内偏移
