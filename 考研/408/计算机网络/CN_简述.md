## 1. 概述

### 1.1 概念

**计算机网络**是由若干**节点**和连接这些节点的**链路**组成，并控制节点间数据通信的结构。

1. 节点包括计算机、交换机、路由器等在网络中具有原子性的设备。
2. 链路包括铜线、电缆、光纤等具有信号传输能力的物理线路。
   - 信号的源头、通道和终点称为**信源**、**信道**、**信宿**。
3. 通常按范围将计算机网络作以下划分：
   1. **局域网**，简称LAN，小范围互连，例如家庭WiFi，校园网、企业网；
   2. 城域网，简称MAN，城市范围互连；
   3. **广域网**，简称WAN，国家级范围互连。
4. 由全球众多网络连接而成的网络称为**互联网**。
5. 局域网接入互联网依赖**互联网服务提供者**，Internet Service Provider，简称**ISP**。
   1. 骨干ISP：电信的广域网，全国长途光纤，对接国际海缆；
   2. 地区ISP：电信的的城域网，是电信广域网的一个子网；
   3. 接入ISP：提供宽带入户的区域运营商。
6. 不同的ISP之间互连，需要互联网交换点，Internet eXchange Point，简称**IXP**。
   - 电信和联通的网络互连，依赖位于北京、上海、广州、成都、西安的国家IXP。



### 1.2 架构

计算机网络采用**分层架构**。

1. 各层级相对独立，不关注其他层级的实现；
2. 上层依赖相邻下层的服务/接口，不跨层依赖；
3. 下层不依赖上层。

规定网络中数据交换和同步问题的规则称为**协议**，通常包含以下三个要素：

1. 语法：数据和控制信息的数据结构。
2. 语义：数据交换的操作。
3. 同步：操作顺序。

协议用于相同层级的主体之间的通信。



开放系统互连（**OSI**）参考模型分层：

1. 物理层：物理接口的编码方式、物理特性和电气特性
2. 数据链路层：网络节点之间通信；
3. 网络层：主机之间通信，IP协议；
4. 传输层：进程之间通信，TCP、UDP协议；
5. 会话层
6. 表示层
7. 应用层

TCP/IP模型分层：

1. 网络接入层：OSI物理层+数据链路层
2. 网络层
3. 传输层
4. 应用层：OSI会话层+表示层+应用层



### 1.3 指标

二进制的一**位**（bit，0或1）是信号的基本单位。称8位为一个**字节**（Byte）。常用计数如下：

1. $K=10^3,M=10^6,G=10^9$；
2. $T=10^{12},P=10^{15},E=10^{18}$
3. $Z=10^{21},Y=10^{24}$。

性能指标：

1. **带宽**通常指信道的最高数据传输速率，单位为位每秒，即b/s。
2. **吞吐量**指单位时间内通过某个网络的数据量。
3. 总时延=发送+传播+处理+排队。
   1. **发送时延**指信源发送数据到信道的时间，**传播时延**指数据在信道传播的时间。
   2. **处理时延**指节点处理数据的时间，**排队时延**指数据等待被节点处理的时间。
   3. **时延带宽积**=传播时延$\times$带宽，表示信道能容纳的最大数据量。
   4. **往返时延**（RTT=传播+处理+传播）表示发送端发出信号到收到接受端确认的最短时间。
4. **信道利用率**指有数据通过的时间占总时间的百分比，过低浪费资源，过高容易拥堵。

非性能指标：费用、质量、标准化、可扩展性、易于维护

1. 可靠传输：发送方发出的数据被接收方正确完整地接收。
