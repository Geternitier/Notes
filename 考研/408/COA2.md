# COA2



## 3. 存储

### 3.1 存储结构

#### 概述

芯片通常由内核、高速缓存、内存控制器、通信基带、片上总线、外部总线接口等构成。

1. **高速缓存 Cache**，又分L1、L2、L3等级别，是紧贴CPU内核的存储器。
2. **内存**：常规读写时逐级Cache未命中，CPU使用内存控制器从内存读取数据到Cache。
3. **外存**：从外设（硬盘）获取数据，写入内存。

也存在部分场景，数据不经Cache而是直接在内核和内存间传递，例如：

1. 网卡、显卡等设备寄存器保存实时信息不可缓存；
2. 读写大批量一次性数据时，可以软件指定绕过缓存。



#### 数据结构

存储器由若干可被唯一标识并存储一个数值的**存储单元**构成。

1. 存储单元的唯一标识符称为**地址**，地址的总和称为**地址空间**；
2. **存取时间**是一次读/写操作所需时间。
3. **存储周期**是完成两次连续独立读/写操作所需的最小时间间隔。
7. **存储带宽**是存储器每秒能传递的最大数据量。



#### 物理结构

存储芯片由存储体、读写电路、地址译码器和控制电路等部分构成。



##### 存储体

**随机存取存储器 RAM**：快速存取，数据易失，需要供电。

1. Static RAM，SRAM：使用MOS晶体管存储数据，供电可以一直维持数据。
2. Dynamic RAM，DRAM：使用电容，根据电荷阈值确定数据，会缓慢失去电荷。
3. Synchronized DRAM，SDRAM：数据发送与时钟信号同步。
4. Double Data Rate SDRAM，DDR：每个时钟周期在时钟脉冲的上升沿和下降沿各发送一次数据。

**只读存储器 ROM**：非易失，不需要供电维持；可读但不能写。

1. 可编程ROM，PROM：可以使用电信号等专门设备写入一次。
2. 可擦除PROM，EPROM：光擦除，电写入，更贵但能多次改写。
3. 电EPROM，EEPROM：随时写入。更贵，密度低于EPROM。
4. 快闪存储器，Flash Memory：电可块级擦除，密度与EPROM相同，价格在EPROM和EEPROM间。

SRAM和DRAM对比：

1. SRAM更快
2. DRAM位元更小，数据密度更高，价格更低
3. DRAM需要支持刷新的电路
4. DRAM常用于主存，SRAM常用于高速缓存



##### DRAM技术

定期刷新：DRAM电荷会流失，需要刷新

1. 集中式刷新：停止读写内存并刷新每一行；刷新时无法操作内存
2. 分散式刷新：在每个存储周期内，当读写操作完成时进行刷新
   - 会增加每个存储周期的时间
3. 异步刷新：每一行各自以64ms间隔刷新；效率高，较常用

行列地址引脚复用：行地址和列地址通过相同的地址引脚分先后传递。

1. 设可存储数据$2^n\times b$位，其中$r$行$c$列，$r\times c=2^n$，$|r-c|$应尽量小来减少引脚数量。
2. 需要周期按行刷新数据存储，因此行数应当更少，需满足$r\le c$。

突发传输：提供首地址和突发长度，一次读取多个数据。

1. 设置行缓冲器，一次缓存一行的全部数据。
2. 不需每个数据都发送一次地址，一次地址可连续发送一行数据。



##### 多模块存储器

使用空间并行，结构相同的存储模块提高存储器的吞吐率。

1. 单体多字存储器：多个存储单元分别存储，一次并行读出多个数据。
2. 多体并行存储器：多个模块独立读写。
   - 高位交叉编址（顺序方式）：顺序在多个存储器上存储。
   - 低位交叉编址（交叉方式）：地址模以模块数，在对应模块上存储



##### 内存读写

读取数据时：

1. CPU将目的地址写入**存储地址寄存器**（Memory Address Register，**MAR**）。
2. 目的地址通过地址总线从MAR传输到内存。
3. 内存将数据通过数据总线传输到**存储数据寄存器**（Memory Data Register，**MDR**）。

写入数据时：

1. CPU将目的地址写入MAR。
2. 目的地址通过地址总线从MAR传输到内存。
3. CPU将数据通过数据总线从MDR传输到内存。

MAR与地址总线位数相同，地址总线的位数决定了最大寻址范围。

MDR与数据总线位数相同，决定了一次能传递的数据位数。

**芯片扩展**：多个芯片组成一个整体。

1. 位扩展：地址线不变，数据线增加
   - 使用8块4K * 1bit的芯片组成4K * 8bit的存储器
2. 字扩展：地址线增加，数据线不变
   - 使用4个16K * 8bit的芯片组成64K * 8bit的存储器

3. 字、位同时扩展：地址线和数据线都增加
   - 使用8个16K * 4bit的芯片组成64K * 8bit的存储器

存储芯片访问：片选（选择芯片）、字选（访问存储单元）

1. 线选：高位地址线直连芯片，当电位为0时选择该芯片（n位地址决定n个芯片）
2. 译码片选：高位地址译码器选片（n位地址选择$2^n$个芯片）



### 3.2 Cache

#### Cache读写

**原理**：

1. 内存墙：CPU的速度比内存快，且两者差距不断扩大
2. 程序访问的局部性原理：处理器频繁访问主存中相同位置或者相邻存储位置的现象

   - 时间局部性：在相对较短的时间周期内，重复访问特定的信息
   - 空间局部性：在相对较短的时间内，访问相邻存储位置的数据
     - 顺序局部性：数据被线性排列访问时，出现的一种空间局部性特殊情况

**流程**：当CPU试图访问主存中的某个字时，首先检查这个字是否在Cache中。

1. 命中：在Cache中，把这个字返回给CPU
2. 未命中：不在Cache中，将包含这个字的主存中的固定大小的块读入Cache，再从Cache中将字传输给CPU。

时间计算：命中率$p$，Cache访问时间$T_C$，主存访问时间$T_M$，平均访问时间$T_A$

1. $T_A=T_C+(1-p)T_M$
2. $p$越大，$T_C$越小，效果越好。
3. $T_A\lt T_M$的条件是$p\gt \frac{T_C}{T_M}$
4. Cache增大使得$p$增大，但$T_C$也增加

**写策略**：

1. 写直达：所有写操作同时对Cache和主存进行。

   - 优点：确保主存中数据总是和Cache中一致。
   - 缺点：产生大量主存访问，减慢写的操作。
2. 写回法：先更新Cache，被替换时，若修改则写回主存。

   - 利用一个使用位表示块是否被修改。

   - 优点：减少了访问主存的次数。
   - 缺点：部分主存数据可能不是最新的。



#### Cache映射

主存和Cache映射：假设Cache有$2^c$行，主存$2^m$块。

1. 直接映射：主存中每一块映射到固定的Cache行，主存地址高$m-c$位作为标记。

   - 主存第$j$块映射到第$i$行：$i=j\;mod\;2^c$
   - 即主存地址由$m-c$位标记，$c$位行号和块内地址组成。
     - 查找时，先根据行号查Cache，然后比对标记。
   - 缺点：抖动现象（Thrashing），程序重复访问两个需要映射到同一行中且来自不同块的字，则这两个块不断被交换到Cache中导致命中率下降
2. 关联映射：一个主存块可以装入Cache任意一行

   - 将块装入空行，满之后根据特定算法进行替换。
   - 缺点：搜索需要遍历每一行，适合小容量Cache

3. 组关联映射：Cache分为多个组，主存块装入固定组的任意行

   - 假设有$2^s$组，则主存地址前$m-s$位为标记，接下来$s$位为组号
   - $k=c-s$，又称$2^k$路组关联映射。



替换算法：随机 RAND，先进先出 FIFO，近期最少使用 LRU，最不经常使用 LFU

1. LRU：最近使用过的内存块更可能被再次使用

   策略：替换掉Cache中最长时间未被访问的内存块

   实现：2路组关联映射

   1. 每行包含一个USE位
   2. 在同一组中的行被访问时，将其USE值设为1，将另一行的USE位设为0
   3. 新数据块读入时，替换USE值为0的数据块

   4路组关联映射

   1. 每行包含两个USE位
   2. 在同一组中的行被访问时，将其USE值清0，其余非空行的USE值+1。
   3. 新数据块读入时，替换USE值最大的数据块

2. LFU：访问越频繁的数据块越有可能被再次使用

   策略：替换掉Cache中被访问次数最少的数据块

   实现：为每一行设置计数器



### 3.3 外存

用于存储不经常使用的、数据量较大的信息；非易失

#### 磁盘

由涂有可磁化材料的非磁性材料构成的圆形盘片，分为**软盘**和**硬盘**。

硬盘结构：
1. **磁盘驱动器**驱动磁盘转动并在盘面上通过磁头进行读写；
2. **磁盘控制器**是磁盘驱动器与主机的接口；
3. **存储区**包含多个盘片：
   1. 每个盘片有两个盘面，每个盘面有一个读写磁头。
   2. 盘面上有多个同心圆结构的磁道，相邻磁道间存在间隙。
   3. 磁道分为多个扇区，相邻扇区间存在间隙，相邻多个扇区组合成簇，按簇读写。
   4. 不同盘片相同位置的磁道构成柱面。
4. 磁盘地址：「柱面（磁道）号｜盘面号｜扇区号」。
   1. 沿磁盘半径方向单位长度上的磁道数称为**道密度**；
   2. 磁道单位长度上的位数称为**位密度**；
   3. 盘面单位面积上的位数称为**面密度**，是位密度和道密度的乘积。

磁盘容量：
1. 非格式化容量：可用磁化单元总数，记录面数$\times$柱面数$\times$每条磁道的磁化单元数；
2. 格式化容量：按某种特定格式能容纳的量，记录面数$\times$柱面数$\times$每道扇区数$\times$每扇区容量。

**存取时间**=寻道时间+旋转延迟+传输时间：

1. **寻道时间**是磁头定位到磁道的时间；**寻道算法**有
   1. 先来先服务 FCFS
   2. 最短寻道时间优先 SSTF
   3. 扫描/电梯 SCAN：磁头按照一个方向移动到边缘，然后返回
   4. 循环扫描 CSCAN：磁头只在往一个方向移动时进行读写，返回时不处理
   5. 电梯 LOOK：SCAN时，如果方向上没有请求就返回
   6. 循环电梯 CLOOK：CSCAN时，如果方向上没有请求就返回
2. **旋转延迟**是磁头转到扇区起始处的时间，**平均旋转延迟**是旋转半周的时间；
3. **传输时间**：数据传输速率$rN$，其中磁盘转速$r$转每秒，每条磁道容量$N$字节。
   - 需要传输$b$字节，则传输时间$\frac{b}{rN}$。



#### 固态硬盘

**U盘**采用了快闪存储器，非易失，比软盘和光盘体积小、容量大、便携、寿命长。

**固态硬盘 SSD**与U盘本质相同，容量更大，存储性能更好。

1. 与硬磁盘存储器相比：抗振性好、无噪声、能耗低、发热少
2. **磨损均衡**：闪存的擦写次数有限，如果集中在几个闪存块进行读写，会导致其磨损较快
   - 动态磨损均衡：写入时自动选择较新的闪存块
   - 静态磨损均衡：SSD自动检测并进行数据分配，使得平时的读写在较新的闪存块进行



#### 冗余磁盘阵列

简称RAID。

1. RAID0：无冗余、无校验磁盘阵列，通过多个磁盘进行存储提高读写速度
2. RAID1：镜像磁盘阵列，通过磁盘镜像提高安全性
3. RAID2：海明码磁盘阵列
4. RAID3：位交叉奇偶校验磁盘阵列
5. RAID4：块交叉奇偶校验磁盘阵列
6. RAID5：无独立校验的奇偶校验磁盘阵列
