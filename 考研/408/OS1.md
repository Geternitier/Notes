# OS1



## 1. OS概述

### 1.1 概念

**操作系统 OS**是计算机管理资源、提供用户接口的系统软件。

1. 管理资源：
   - 处理器：包括进程控制、同步、通信，死锁处理，处理器调度等；
   - 存储：内存分配与回收、地址映射、内存保护与共享、内存扩充；
   - 文件：文件存储管理、目录管理、读写管理；
   - 设备：缓冲管理、设备分配与处理、虚拟设备。
2. 用户接口：
   - 命令接口：
     - 联机命令接口：命令行
     - 脱机命令接口：批处理命令
     - 图形用户接口
   - 程序接口：系统调用

**操作系统的特征**：

1. **并发**：多个事件在同一时间间隔内发生。
   - **并行**：多个事件在同一时刻发生。
2. **共享**：资源可供多个并发执行的进程同时使用。
   - 互斥共享：申请与释放
   - 同时访问：可能是分时访问
3. **虚拟**：
   1. 虚拟处理器进行时分复用；
   2. 虚拟存储器进行空分复用；
   3. **虚拟机**通过虚拟化层逻辑化原先的物理设备，实现软硬件解耦。
      - 硬件级虚拟化（Hypervisor）：CPU、内存、I/O设备
      - 操作系统级虚拟化（Docker、VMWare WorkStation）
4. **异步**：进程是执行、暂停交替的。



### 1.2 历史

1. 无OS
   1. 手工操作：使用穿孔纸带输入数据，手工操作执行；
   2. 脱机：先用额外机器将纸带读入磁带，主机处理后写入磁带，由额外机器输出。
2. 批处理：将一批作业以脱机方式输入，主机在监督程序的控制下逐个运行
   1. 单道：自动、顺序
   2. 多道：使用中断技术，宏观并行，微观串行
3. 分时：将处理器时间分为时间片分配给多任务、多用户进行使用。
4. 实时：在某个时间限制内完成某些任务。具有及时性和可靠性。
   1. 硬实时：必须按时完成
   2. 软实时：允许偶尔错过
5. 网络：结合网络中各台计算机，共享资源，进行通信
6. 分布式：**分布**多个计算机，**并行**完成同一任务
7. 微机OS：
   1. 单用户单任务：一个用户，一个程序
   2. 单用户多任务：一个用户，多个程序，Windows、MacOS
   3. 多用户多任务：Linux



### 1.3 内核

现代操作系统通常将系统核心模块和用户模块以不同模式运行，称为**内核模式**和**用户模式**，核心模块的集合称为**内核**，仅能在内核模式执行的指令称为**特权指令**。

内核功能：

1. 时钟管理
2. 中断控制
   1. 外中断也称**中断**，来自处理器外，如时钟中断、IO中断；
   2. 内中断也称**异常**，来自处理器内，通常是程序执行异常，如访管、硬件故障；
   3. 指令执行周期中包含中断检查。
3. 资源管理：处理器、存储、设备、文件
   1. **系统调用**是内核提供给用户的资源管理接口。
   2. 系统调用过程：
      1. 用户传递参数，执行Trap指令，CPU切换至内核模式；
      2. 保护现场后，根据调用号查找调用表，执行对应地址的服务程序；
      3. 恢复现场，返回用户模式，继续执行。

内核结构：

1. 宏内核：系统的主要功能模块集中在内核中；
2. 微内核：保留基本功能，其余功能作为用户态的服务与内核进行通信。

操作系统引导：

1. CPU通电，从ROM中读取并执行BIOS；
2. BIOS自检并选择启动设备，加载boot程序；
3. boot程序加载内核；
4. 内核执行操作系统初始化。



## 2. 处理器管理

### 2.1 进程

#### 概念

**进程 Process**是OS控制程序运行的数据结构，是OS资源分配和调度的基本单位。

1. **进程映像**是内存存储的进程实体，包含进程控制块、程序段、数据段；
2. **进程控制块 PCB**是描述进程情况和状态的数据结构。
   1. 标识：进程ID、父进程ID、用户ID
   2. 控制信息：状态、优先级、信号量、CPU占用时间、进入内存时间等
   3. 资源分配信息：段指针、文件描述符
   4. 处理器信息：通用寄存器、程序计数器、程序状态字、栈指针

**进程通信 IPC**的方式：

1. 共享存储；
2. 消息传递：直接（发送给对应进程）、间接（信箱）；
3. 管道：使用内存缓冲区进行通信；



#### 状态

进程的状态包含就绪、运行、阻塞，以及短暂的新建（资源分配）和结束（资源回收）。

1. 就绪态$\rightarrow$运行态：处理器空闲时选择、优先进程抢占；
2. 运行态$\rightarrow$阻塞态：等待资源；
3. 阻塞态$\rightarrow$就绪态：资源满足；
4. 运行态$\rightarrow$就绪态：运行时间片到、优先进程抢占。

进程控制：

1. 进程创建：终端用户登录、作业调度、系统提供服务、用户程序请求
   1. 分配进程ID，申请PCB。
   2. 分配资源，初始化PCB。
   3. 设为就绪态。
2. 进程终止：正常结束、错误终止、外界干预
   1. 检查进程状态
   2. 释放进程资源
   3. 删除进程控制块
3. 进程阻塞：等待某些操作完成
4. 进程切换：
   1. 挂起进程，保存CPU上下文到进程控制块
   2. 加载新进程的CPU上下文，执行新进程



#### 线程

进程切换、通信开销大；并发粒度受限，并行计算效率低。因此引入线程。

**线程**是进程的一条执行路径，是调度的基本单位。

1. 线程的状态：就绪、运行、等待
2. 线程的组织：线程控制块（线程标识符、控制信息、处理器相关信息、资源信息）

线程的实现：

1. 用户级线程：用户程序提供多线程环境，进行线程管理，内核不知线程的存在

   特点：

   - 线程切换不需要模式切换，系统开销小
   - 允许进程按特定需要选择调度算法
   - 能运行在任何操作系统上
   - 不能利用多处理器，操作系统调度进程，只有一个ULT能执行
   - 一个ULT的阻塞将引起整个进程的阻塞

2. 内核级线程：操作系统内核管理与调度线程、提供使用线程的程序设计接口

   特点：

   - 进程的一个线程阻塞，内核能调度同一进程的其他线程运行
   - 多处理器环境中，内核能同时调度同一进程的多个线程并行执行
   - 内核自身也可用多线程技术实现，提高操作系统执行速度和效率
   - 应用程序线程在用户态而线程调度在内核态，因而线程切换需要模式切换，系统开销大

3. 混合式线程：建立内核级线程和用户级线程间的映射关系



### 2.2 调度

处理器调度：选择进程分配处理器运行。

调度层次：

1. 高级调度：新建和结束进程，决定进程能否加入执行的进程池中；
2. 中级调度：进程挂起与恢复，决定主存中的可用进程集合；

3. 低级调度：处理器分配，决定哪个进程占用处理器执行。

调度时机：

1. 决定两个就绪的进程谁先执行；决定是否抢占
2. 进程结束/挂起后调度进程执行
3. 时间片轮转

调度衡量指标：

1. CPU利用率：工作时间/(工作时间+等待时间)；
2. 系统吞吐量：单位时间内CPU完成作业数；
3. 周转时间：作业从提交到完成的时间间隔。

调度算法：

1. **先来先服务 FCFS**：长作业会让短作业等待很久，有利于CPU繁忙型作业
2. **短作业优先 SJF**：长作业饥饿
3. **高响应比优先**：响应比$=\frac{等待时间+工作时间}{工作时间}$。
4. **时间片轮转**
5. **优先级调度**：静态优先级与动态优先级
   - 优先级设置：系统$>$用户，交互$>$非交互，IO$>$计算。
6. **多级队列**：不同队列使用不同调度算法
   - 多级反馈队列：动态优先级
