# COA1



## 1. 计算机概述

### 1.1 冯·诺伊曼机

**冯·诺伊曼计算机**的三个核心思想：

1. **二进制**：信息用两种状态表示。
2. **存储程序**：指令和数据保存在存储器中，机器自动逐条读取指令执行。
3. **组成部分**：存储器、控制单元、算术逻辑单元 ALU、输入/输出设备。
   1. **存储器**包括缓存、内存和外存；
   2. **中央处理器 CPU**包含**控制单元和数据通路**，数据通路包含ALU、寄存器、数据传输元件；
   3. **输入/输出 I/O设备**也称外设，通过**设备控制器**控制，设备控制器又称**I/O接口**；
   4. **总线**在CPU、存储器、I/O设备间传递数据。



### 1.2 软件

软件是能实现某种功能的指令和数据集合。

软件和硬件是逻辑等价的，一项功能既可以纯硬件实现，也可以硬件+软件实现。

软件语言层次结构：

1. **机器语言**是处理器识别和执行的程序，由二进制序列构成。
   1. 机器语言决定了软件可用的硬件功能；
   2. 机器语言的规范称为**指令集架构 ISA**；
   3. 处理器的**微架构**决定机器指令的执行方式，相同ISA可以有不同微架构。
2. **汇编语言**用简单符号包装机器语言，通过**汇编**翻译为机器语言执行。
3. **高级语言**是复杂组织形式的代码，通过**编译/解释**翻译为汇编/机器语言。
   1. 编译：将高级语言按其结构翻译为汇编或机器语言。
   2. 解释：将高级语言逐条翻译为机器语言。



### 1.3 参数

**机器字长**是计算机进行一次整型运算能够处理的二进制数据位数。

**数据通路带宽**是数据总线一次所能并行传送信息的位数。

运算速度：
1. CPU**时钟周期**是CPU工作最小的时间单位，CPU**主频**是CPU每秒的时钟周期数。
3. **CPI** Cycle Per Instruction是执行一条指令需要的时钟周期数。
4. **IPS** Instruction Per Second是每秒执行指令数，IPS=主频/平均CPI。
6. **FLOPS** Floating-point Operations Per Second是每秒浮点运算数。

常用倍数：

| 符号 | 基 10     | 基 2     |
| ---- | --------- | -------- |
| K    | $10^3$    | $2^{10}$ |
| M    | $10^6$    | $2^{20}$ |
| G    | $10^9$    | $2^{30}$ |
| T    | $10^{12}$ | $2^{40}$ |
| P    | $10^{18}$ | $2^{50}$ |



## 2. 操作系统

### 2.1 概念

**操作系统 OS**是计算机管理资源、提供用户接口的系统软件。

1. 管理资源：
   - 处理器：包括进程控制、同步、通信，死锁处理，处理器调度等；
   - 存储：内存分配与回收、地址映射、内存保护与共享、内存扩充；
   - 文件：文件存储管理、目录管理、读写管理；
   - 设备：缓冲管理、设备分配与处理、虚拟设备。
2. 用户接口：
   - 命令接口：
     - 联机命令接口：命令行
     - 脱机命令接口：批处理命令
     - 图形用户接口
   - 程序接口：系统调用

**操作系统的特征**：

1. **并发**：多个事件在同一时间间隔内发生。
   - **并行**：多个事件在同一时刻发生。
2. **共享**：资源可供多个并发执行的进程同时使用。
   - 互斥共享：申请与释放
   - 同时访问：可能是分时访问
3. **虚拟**：通过虚拟化层逻辑化原先的物理设备，实现软件和硬件解耦。
   1. 硬件虚拟化：虚拟处理器进行时分复用；虚拟存储器进行空分复用；
   2. 操作系统虚拟化。
4. **异步**：进程是执行、暂停交替的。



### 2.2 历史

1. 无OS
   1. 手工操作：使用穿孔纸带输入数据，手工操作执行；
   2. 脱机：先用额外机器将纸带读入磁带，主机处理后写入磁带，由额外机器输出。
2. 批处理：将一批作业以脱机方式输入，主机在监督程序的控制下逐个运行
   1. 单道：自动、顺序
   2. 多道：使用中断技术，宏观并行，微观串行
3. 分时：将处理器时间分为时间片分配给多任务、多用户进行使用。
4. 实时：在某个时间限制内完成某些任务。具有及时性和可靠性。
   1. 硬实时：必须按时完成
   2. 软实时：允许偶尔错过
5. 网络：结合网络中各台计算机，共享资源，进行通信
6. 分布式：**分布**多个计算机，**并行**完成同一任务
7. 微机OS：
   1. 单用户单任务：一个用户，一个程序
   2. 单用户多任务：一个用户，多个程序，Windows、MacOS
   3. 多用户多任务：Linux



### 2.3 内核

现代操作系统的核心模块和用户模块通常以不同模式运行，称为**内核模式**和**用户模式**，核心模块的集合称为**内核**，仅能在内核模式执行的指令称为**特权指令**。

内核功能：

1. 时钟管理
2. 中断控制
   1. 外中断也称**中断**，来自处理器外，如时钟中断、IO中断；
   2. 内中断也称**异常**，来自处理器内，通常是程序执行异常，如访管、硬件故障；
   3. 指令执行周期中包含中断检查。
3. 资源管理：处理器、存储、设备、文件
   1. **系统调用**是内核提供给用户的资源管理接口。
   2. 系统调用过程：
      1. 用户传递参数，执行Trap指令，CPU切换至内核模式；
      2. 保护现场后，根据调用号查找调用表，执行对应地址的服务程序；
      3. 恢复现场，返回用户模式，继续执行。

内核结构：

1. 宏内核：系统的主要功能模块集中在内核中；
2. 微内核：保留基本功能，其余功能作为用户态的服务与内核进行通信。

操作系统引导：

1. CPU通电，从ROM中读取并执行BIOS；
2. BIOS自检并选择启动设备，加载boot程序；
3. boot程序加载内核；
4. 内核执行操作系统初始化。
