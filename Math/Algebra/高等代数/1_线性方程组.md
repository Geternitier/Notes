# 高等代数

丘维声《高等代数》笔记

## 1. 线性方程组

### 1.1 矩阵形式定义

由$mn$个数排成$m$行$n$列的数表，称为$m\times n$矩阵，这$mn$个数称为矩阵的元素。

$\boldsymbol A=\begin{pmatrix}a_{11}&a_{12}&...&a_{1n}\\ a_{21}&a_{22}&...&a_{2n}\\  ...&...&&...\\a_{m1}&a_{m2}&...&a_{mn} \end{pmatrix}$

1. 通常表示为$\boldsymbol A=(a_{ij})_{m\times n}$，也可记为$\boldsymbol A_{m\times n}$。
2. 元素全为0的矩阵称为**零矩阵**，记为$\boldsymbol 0$。
3. 元素都是实数的矩阵称为实矩阵。$\mathbb R^{m\times n}$表示全体$m\times n$实矩阵的集合。
4. $n\times n$矩阵称为$n$阶矩阵，或$n$阶方阵。
5. 将$\boldsymbol A=(a_{ij})_{m\times n}$的行列互换得到的矩阵$(a_{ji})_{n\times m}$称为$\boldsymbol A$的**转置**，记为$\boldsymbol A^T$。

若矩阵$\boldsymbol A,\boldsymbol B$的行数相等，列数相等，且对应位置元素相等，则称$\boldsymbol A$和$\boldsymbol B$相等，记为$\boldsymbol A=\boldsymbol B$。



### 1.2 线性方程组

#### 形式

由若干个$n$元一次方程构成的方程组称为$n$元线性方程组，其基本形式为

$\begin{cases}a_{11}x_1+...+a_{1n}x_n=b_1\\...\\a_{m1}x_n+...+a_{mn}x_n=b_m \end{cases}$，其中$a_{ij}$为系数，$b_i$为常数，$x_i$为未知数。

记$\boldsymbol A=\begin{pmatrix}a_{11}&a_{12}&\dots&a_{1n}\\ a_{21}&a_{22}&\dots&a_{2n}\\\vdots&\vdots&\ddots&\vdots\\a_{m1}&a_{m2}&\dots&a_{mn} \end{pmatrix},\boldsymbol x=\begin{pmatrix}{}x_{1}\\x_{2}\\\vdots\\x_n \end{pmatrix}\boldsymbol b=\begin{pmatrix}{}b_{1}\\b_{2}\\\vdots\\b_{m}\end{pmatrix}$，

则方程组可表示为$\boldsymbol A\boldsymbol x=\boldsymbol b$，称$\boldsymbol A$为系数矩阵，$\boldsymbol x$为未知向量，$\boldsymbol b$为右端向量。



#### 定义

方程组相关定义：

1. **解向量**是代替未知向量使方程组成立的向量，解向量的集合称为方程组的解集。
2. 具有相同解集的两个方程组称为**同解**方程组，同解关系是等价关系。
3. 方程组的某一个解称为**特解**，所有解的集合称为**通解**。
4. 对方程组进行的下述三种变换称为**初等变换**：
   1. 把一个方程的倍数加到另一个方程上；
   2. 互换两个方程的位置；
   3. 用一个非零数乘以某个方程。
5. 常数项全为0的线性方程组称为**齐次线性方程组**，否则为非齐次线性方程组。
   - 非齐次线性方程组对应的齐次线性方程组的通解称为**齐次通解**。

矩阵相关定义：

1. 矩阵$\boldsymbol B=(\boldsymbol A\;\boldsymbol b)$称为$\boldsymbol A\boldsymbol x=\boldsymbol b$的**增广矩阵**。
2. 矩阵$\boldsymbol J$称为**阶梯形矩阵**，若满足：
   1. $\boldsymbol J$的零行（元素全为0的行）都在下方；
   2. 非零行的第一个非0元称为**主元**；$\boldsymbol J$的主元的列坐标逐行严格递增。
3. 矩阵$\boldsymbol J$称为**行简化阶梯形矩阵**，若满足：
   1. $\boldsymbol J$为阶梯形矩阵；
   2. $\boldsymbol J$的主元都是1；
   3. $\boldsymbol J$的每个主元所在列的其余元素都是0。
4. 线性方程组的初等变换对应矩阵的**行初等变换**：
   1. 把某一行的倍数加到另一行上；
   2. 互换两行的位置；
   3. 用一个非零数乘以某一行。
5. 增广矩阵的行简化阶梯形矩阵中，主元对应的未知量称为**主变量**，其他变量为**次变量**。



#### 高斯消元法

求解方程组的过程，就是通过初等变换消元，逐个得到单一未知量值。以矩阵形式而言，就是通过行初等变换，将增广矩阵化为行简化阶梯形矩阵，观察矩阵得到解向量。这个方法称为**初等变换法**，也称**高斯消元法**。

**定理**：任一矩阵都可以经过一系列行初等变换，化为行简化阶梯形矩阵。

解的结构讨论：增广矩阵化为行简化阶梯形矩阵后，可以观察矩阵获得解

1. 若系数矩阵部分的主元数少于增广矩阵的主元数，说明有方程$0=d\neq0$，此时无解。
2. 若所有变量都是主变量，此时方程组简化为$x_1=d_1,...,x_n=d_n$，得唯一解。
3. 若存在次变量，由于主变量和次变量可以按比例转换，有无穷多解。
   1. 不妨设主变量为$x_1,...,x_r$，次变量为$x_{r+1},...,x_n$，
   2. 方程组简化为$\begin{cases}x_1+\sum_{i=r+1}^nk_{1i}x_i=d_1\\...\\x_r+\sum_{i=r+1}^nk_{ri}x_i=d_r\end{cases}$；
   3. 取主变量$x_i=d_i,1\le i\le r$，次变量为0，可得一个特解；
   4. 给次变量取值，并按方程组给主变量加上对应的值，可得无穷多个解；

**齐次通解**：上述的主变量和次变量的关系就是齐次通解

1. 简化后的方程组$\begin{cases}x_1+\sum_{i=r+1}^nk_{1i}x_i=0\\...\\x_r+\sum_{i=r+1}^nk_{ri}x_i=0\end{cases}$；
2. 取某个次变量$x_i=-1,r+1\le i\le n$，其他次变量为0，主变量$x_j=k_{ji}$，方程组成立；
3. 可得$n-r$个特解，这些特解的任意线性组合就是齐次通解，
4. 齐次通解形式为$\boldsymbol x=\sum_{i=r+1}^nk_i\boldsymbol x_i$，其中$\boldsymbol x=\begin{pmatrix}x_1\\...\\x_r\\x_{r+1}\\...\\x_n\end{pmatrix}$，$\boldsymbol x_i=\begin{pmatrix}k_{1i}\\...\\k_{ri}\\0\\...\\0\end{pmatrix}-\boldsymbol e_{i}$。
   - $\boldsymbol e_i$表示第$i$位为1，其余位为0的标准向量。

**解的结构**：线性方程组可能无解、有唯一解、有无穷多解

1. 若系数矩阵的主元数少于增广矩阵，无解。
2. 若所有未知量都是主变量，有唯一解。
3. 存在次变量，有无穷多解，通解为特解和齐次通解的和。



### 1.3 行列式

#### 逆序数

$n$个不同数的一个**全排列**称为一个$n$元排列。

1. 例如，123的3元排列为123、132、213、231、312、321；
2. $n$个不同数的全排列有$n!$个。

给定$n$元排列$a_1a_2\dots a_n$，从左到右每两个数构成一个**数对**。若一个数对中大的数在前，称这个数对构成一个**逆序**，一个排列中构成逆序的数对总数称为该排列的**逆序数**，记为$\tau(a_1a_2\dots a_n)$。逆序数为偶数的排列称为**偶排列**，逆序数为奇数的排列称为**奇排列**。

1. 例如，$12\dots n$是一个偶排列。
2. 在$n$元排列$a_1a_2\dots a_n$中交换某两个数$a_i,a_j$的位置，其余数不变，这称为一个**对换**$(a_i,a_j)$；
3. 对换改变排列的奇偶性。
4. $1,2,\dots,n$的任意排列可经过一系列对换化为$12\cdots n$，且对换个数与这个排列奇偶性相同。



#### 形式定义

$n$阶矩阵$\boldsymbol A=(a_{ij})_{m\times n}$的行列式为

$\boldsymbol A=\begin{vmatrix}a_{11}&a_{12}&\dots&a_{1n}\\ a_{21}&a_{22}&\dots&a_{2n}\\\vdots&\vdots&\ddots&\vdots\\a_{m1}&a_{m2}&\dots&a_{mn}\end{vmatrix}=\sum_{j_1j_2\dots j_n}(-1)^{\tau(j_1j_2\dots j_n)}a_{1j_1}a_{2j_2}\dots a_{nj_n}$

其中$\sum_{j_1j_2\dots j_n}$表示遍历$1,2,\dots,n$的所有$n$元排列$j_1j_2\dots j_n$求和。

**三角行列式**：

1. 行列式左上角到右下角的连线称为**主对角线**，右上角到左下角的连线称为**反对角线**。
2. 主对角线下方全为0的行列式称为**上三角行列式**，上三角行列式的值为主对角线元素的积。

**子式**：子式、主子式、顺序主子式、余子式的概念同等适用于矩阵。

1. 行列式的任意$k$行$k$列交点元素构成的行列式称为行列式的**$\boldsymbol k$阶子式**。
2. 若子式所选取的行和列具有相同的坐标，称该子式为行列式的**主子式**。
3. 行列式前$k$行$k$列交点元素构成的子式称为行列式的**顺序主子式**。
4. 行列式除去第$i$行和第$j$列得到的行列式$M_{ij}$称为元素$a_{ij}$的**余子式**。
   - $A_{ij}=(-1)^{i+j}M_{ij}$称为元素$a_{ij}$的**代数余子式**。
5. 设子式由行列式的$i_1,\dots,i_k$行，$j_1,\dots,j_k$列指定，
   - 原行列式除去这$k$行$k$列得到的行列式$M$称为该**子式的余子式**。
   - $(-1)^{i_1+\dots+i_k+j_1+\dots+j_k}M$称为该**子式的代数余子式**。



#### 值的性质

**变换性质**：

1. $|\boldsymbol A^T|=|\boldsymbol A|$，行列式转置值不变，因此行列式所有行的性质都能适用于列。
2. 初等行变换：下述性质类似地对初等列变换适用
   1. 两行互换，行列式的值取负。于是两行相等的行列式值为0。
   2. 任一行元素的公因子可以提出到行列式外。于是两行相互成比例的行列式值为0。
   3. 某行每个元素都可表示为两数之和，则行列式可以按该行分解为两行列式的和。
      - 把某行的$k$倍加到另一行，行列式的值不变。

**展开式**：

1. 行列式的值等于它的某行元素与各自代数余子式的乘积和，即$|\boldsymbol A|=\sum_{j=1}^na_{ij}A_{ij}$。
2. 行列式的某行元素与另一行相应元素的代数余子式的乘积和为0，$\sum_{j=1}^na_{ij}A_{kj}=0$。
3. **Laplace定理**：行列式的值等于任取$k$行中所有$k$阶子式与其代数余子式乘积的和。
   - $\begin{vmatrix}\boldsymbol A&\boldsymbol 0\\\boldsymbol D&\boldsymbol B\end{vmatrix}=|\boldsymbol A||\boldsymbol B|$，其中$\boldsymbol A,\boldsymbol B$都是方阵。
   - $\begin{vmatrix}\boldsymbol 0&\boldsymbol A\\\boldsymbol B&\boldsymbol D\end{vmatrix}=(-1)^{mn}|\boldsymbol A||\boldsymbol B|$，其中$\boldsymbol A$为$m$阶方阵，$\boldsymbol B$为$n$阶方阵。



#### 克莱默法则

对于含$n$个方程的$n$元线性方程组$\boldsymbol A\boldsymbol x=\boldsymbol b$，可以用系数行列式来判断其是否有唯一解，用系数行列式和右端矩阵来求唯一解。

唯一解判别讨论：

1. 由高斯消元法可得，线性方程组有唯一解时，$\boldsymbol A$的行简化阶梯形矩阵$\boldsymbol J$有$n$个主元。
2. 此时$|\boldsymbol J|\neq 0$，由于初等行变换对行列式的值只进行非零的数乘，$|\boldsymbol A|\ne0$。
3. 若$\boldsymbol b=\boldsymbol 0$，齐次线性方程组有唯一解意味着方程组只有零解。

唯一解求解讨论：

1. 将系数矩阵写为列向量形式，$\boldsymbol A=(\boldsymbol a_1,\dots,\boldsymbol a_n)$；
2. 对任一$x_k$有$x_k|\boldsymbol A|=|\boldsymbol a_1,\dots,x_k\boldsymbol a_k,\dots,\boldsymbol a_n|$；
3. 把第$k$列以外的每一列$\boldsymbol a_i$乘以$x_i$加到第$k$列，行列式的值不变，且$\sum_{i=1}^n x_i\boldsymbol a_i=\boldsymbol b$；
4. $x_k|\boldsymbol A|=|\boldsymbol a_1,\dots,\boldsymbol a_{k-1},\boldsymbol b,\boldsymbol a_{k+1},\dots,\boldsymbol a_n|$；
5. 记用$\boldsymbol b$替换$\boldsymbol A$的第$k$列的矩阵为$\boldsymbol B_k$，$x_k=\frac{|\boldsymbol B_k|}{|\boldsymbol A|}$。

**定理**：克莱默法则

1. 含$n$个方程的$n$元线性方程组$\boldsymbol A\boldsymbol x=\boldsymbol b$有唯一解的充要条件是$|\boldsymbol A|$不为0。
2. 当$|\boldsymbol A|\ne0$，$\boldsymbol A\boldsymbol x=\boldsymbol b$的解为$x_k=\frac{|\boldsymbol B_k|}{|\boldsymbol A|},1\le k\le n$。
